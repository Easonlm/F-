新 $Q\times N\times D$ 的公式为 $L=L_{ND}+G(1-Q)^\kappa N^{-\eta_N}(D/100)^{-\eta_D}$，估计 $\eta_D=0.03965$，按 B6 的 N 簇重采样区间 [0.02348,0.05327]。它对 B6 半合成规律的适配稍好，但 B7 留出收益不稳、B8 跨源没有改善，因此只保留为敏感性模型。B6 与 B8 有 160 个完全相同的 $(N,D,Q)$ 输入，却全部对应不同 Loss；两来源等权时，任一不读来源标签的确定性预测在这些点上的理论 RMSE 下界约 0.69768。此冲突不能靠增加同一公式的参数消除。

### 可选的 B8 有标签来源适配

新增 [`source_quality_calibration.py`](source_quality_calibration.py) 作为**显式选择**的 B8 适配接口。它先固定主 Model C 的 $L_{NDQ}$，再用 B8 校准行拟合残差

\[
r_8=b_0+b_1(Q-0.5)+b_2\log N+b_3\log D+b_4(Q-0.5)\log N+b_5(Q-0.5)\log D.
\]

Ridge 惩罚系数只在校准集内按 N–D 单元分组交叉验证选择。调用者必须提供 B8 数据文件、校准 ID 文件和测试 ID 文件；接口拒绝同一行或同一 N–D 单元进入两侧。全交互式还要求**每个校准 N 至少两个不同 D 单元**。适配模型另存 `b8_labeled_source_calibrator.joblib`，不改主 artifact，也不自动进入问题三、四。

| B8 协议与标签成本 | 零样本主模型 | 同标签预算的截距校准 | 来源 Q 交互校准 | 证据边界 |
|---|---:|---:|---:|---|
| 每 N 两个 D 单元：校准 200/1480 条 B8 新点（30 单元），其余 1280 条（120 新单元）测试 | 1.3351 | 0.7517 | **0.1336** | 校准标签占所选 1480 条的 13.5%；新 D 单元但共享 Q 水平。 |
| 校准 102 条、5 个 Q 水平；测试 728 条、7 个完全未见 Q 水平，同时 N–D 单元不交叉 | 1.2826 | 0.7804 | **0.1279** | 对 Q 水平和 N–D 单元双重留出；仍是同一 B8 来源。 |
| 只用 `data_type=calibrated` 的 56 条标签，测试 $N\ge20$ 的 720 条 `extrapolated` 标签 | 1.2767 | 0.6987 | **0.1858** | 测试目标是附件估算值，不能视作现实大模型实测。 |
| 每 N 仅一个 D 单元：校准 100 条、测试 1380 条 | 1.3291 | 0.7608 | **0.7550** | 全交互外推失败；默认模式拒绝该设计。显式 `q_only` 模式在同一划分上达到 0.2387。 |

**显式低标签模式。** 对每 N 只有一个 D 锚点的情形，接口现提供 `--mode q_only`，仅拟合 $r_8=b_0+b_1(Q-0.5)$。在固定的 100 校准/1380 测试行上，Q-only RMSE 为 **0.2387**，相同 100 标签预算下的截距校准为 **0.7608**；按 135 个测试 N–D 单元成对重采样，RMSE 差 95% 区间 [-0.5512,-0.4935]。把校准 Q 限为 5 个水平、测试限定另 7 个未见 Q 水平且 N–D 单元不交叉时，51 校准/777 测试行的 Q-only RMSE **0.2207**，截距为 **0.8080**，111 单元成对重采样差区间 [-0.6115,-0.5621]。后一划分含已知 B8 质量量尺上的新 Q 值，并非外部来源验证。`q_only` 与 `full_interaction` 必须由用户显式选择，校准内 CV 仅选择惩罚强度。**100/1380 与 200/1280 的标签预算及测试行不同，两个协议的 RMSE 不能直接排名。**

标准 200 标签协议下，来源交互与截距校准的 RMSE 差为 -0.6181；以 120 个测试 N–D 单元成对重采样所得 95% 区间 [-0.6414,-0.5948]。逐 N 留出后，在其余 N 上各取两个 D 单元校准，1480 行合并 RMSE 为 0.1372，截距校准为 0.7582。另有 160 个 B6/B8 精确重合输入，其 B8 标签未参与 B8 新点校准；适配后 RMSE 0.0652，零样本主模型为 1.3925。

**解释范围：** `full_interaction` 与 `q_only` 都是**使用 B8 附件目标标签的有监督预测校正**。它们可能改变 $Q\to L$ 的方向，只表示 B8 口径中的统计关系，不能当通用数据质量机制，也不能传给问题三、四。B8 含 `calibrated` 和 `extrapolated` 数据，不能据此声称同等程度地改善真实跨模型族训练 Loss。适配式只校正 N–D–Q；A 组质量量尺 $Q_A\to Q_B$ 与配比幅度仍未识别。主 Model C 的零样本跨源结论及 P3/P4 输入保持原样。

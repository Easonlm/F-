# 分享说明

- **只发一个文件、让对方直接看图并复制图片**：发送 `四问正式论文_第二版_单文件.html`。对方用浏览器打开，图片已嵌入文件；可在图片上右键复制或保存。
- **让对方继续编辑 Markdown**：发送整个 `四问正式论文_第二版_分享版.zip`。对方解压后打开其中的 `四问正式论文_第二版.md`，并保留同级的 `图片` 文件夹。不要只转发 md。
- 若要双方实时看到后续修改，把解压后的整个文件夹放在共享同步盘中，并共享该文件夹；每次修改 Markdown 或替换图片后，等同步完成。单独发过一次的附件不会自动更新。
- 部分聊天软件不会预览 Markdown 中的本地图片路径；请在 Markdown 编辑器中打开解压后的文档，或直接使用单文件 HTML。

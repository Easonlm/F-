# 四问合稿素材：问题一、二的科学核查与可用文字

**版本口径（2026-09-24）。** 两份用户提供的《四问科研表达与论文结构升级指导报告》《项目全局审计与优化路线》是有价值的研究建议，但形成时问题一尚无 V3、问题二尚无 B8 有标签适配。现行主链仍为 **P1 V2 配比 artifact → P2 Model C → P3/P4**；P1 V3 只作 **1M 条件候选**，P2 的 B8 有标签适配只作**来源特定应用**。下列数字以当前 `problem1/outputs/tables/v3_*`、`problem2_v2/outputs/tables/*` 及各自核验为准，不能用旧审计表覆盖新结果。建议合稿标题主张“证据约束下的配比、标度律与资源配置”，把跨问接口的可计算性与其统计识别边界一起写清。

## 可直接转写：问题一

**方法段。** 我们对 A1–A3 的 **272,505 条质量记录**处理 22 项异向信号，使用 A1 固定转换标尺，将各指标统一到“较高表示规则定义下较好”的方向。样本级质量代理定义为四组分数的等权平均：

\[
Q_A(x)=\tfrac14\{Q_{\rm educational}(x)+Q_{\rm readability}(x)+Q_{\rm cleanliness}(x)+Q_{\rm structure}(x)\}.
\]

教育组中相关性很高的三项 DSIR 先合并为一个子维度，再与另外四项教育信号等权。A1 的第 25/75 百分位定义三类高低指标冲突；主评分不自动扣罚，而把连续惩罚和极端广告惩罚作为敏感性方案。域级分数由样本分聚合，扩展集对照剔除 A1 与 A2/A3 的重合 ID。17 域配比满足单纯形约束，先以对数比进入配比回归。此处的 $Q_A$ 是**工程质量代理**，尚无完成的双人盲评或同配比异质量训练证据。

**结果段。** A1 冲突率在预设 25/75 阈值下为 **7.83%**；改用 20/80 与 30/70 阈值时分别为 **3.93%** 与 **13.62%**，因此冲突率应带阈值报告。A1 与去重扩展集的 arxiv 平均 $Q_A$ 为 **0.7647/0.7616**，github 为 **0.5750/0.5741**，表明相同域的规则分量级接近，并未证明质量代理对训练效用有效。人工盲评 140 条样本的设计已封存，`manual_validation_results.csv` 仍只有表头；正文不得写“人工验证已通过”。质量与配比的映射试验中，固定域 $Q_A$ 由配比决定，缺少同配比异质量的训练对照，不能从微小 RMSE 改善推断 $Q_A$ 的独立作用。

**配比段。** 当前跨问主模型 V2 对配比作二阶 ALR 变换并用 Ridge 预测 13 个验证域 Loss；另建立不含显式两两交互的 CLR 加性三次样条 V3，考察更平滑的领域主效应。两模型均只用 A4/A5 的 512 个 1M 配方选型及拟合，A6–A11 用于既定检验，A12–A15 是估算标签。V3 的同一外层五折嵌套 OOF RMSE 为 **0.2522**，优于 V2 的 **0.3340**，五折均改善；1M 实测为 **0.2082/0.2702**，60M 实测为 **1.5614/1.5959**（V3/V2）。但 1B 为 **2.7357/2.7021**，V3 反而退步。按配方配对 bootstrap，V2−V3 的 RMSE 差在 1M 为 **+0.0620 [0.0445, 0.0791]**，1B 为 **−0.0336 [−0.0605, −0.0069]**。故 V3 是 1M 配比预测的条件候选，跨问仍用 V2；60M 与 1M 检验复用同一配方集合，不可说成两个独立配比测试。V3 的 60M/1B 原始 bias 仍为 **+1.4712/+2.6575**，跨规模绝对 Loss 未解决。训练配方局部置换只能称“模型预测差”，不称因果收益。

**问题一摘要可用一句。** “以全量质量信号构建可复算的 $Q_A$ 代理，并以单纯形对数比模型估计配比—Loss 响应；新样条候选在 1M 嵌套验证和既定测试中改善预测，但 1B 退步与质量真值缺席限定了跨规模和质量效应的解释。”

## 可直接转写：问题二

**主模型段。** 保留 B1 拟合的经典 $N$–$D$ 形式，将 B6 半合成数据中经比较保留的质量×规模项与问题一 V2 配比响应作条件桥接：

\[
\begin{aligned}
L(N,D,Q_B,\mathbf p)={}&1.689798+0.353980N^{-0.339977}
 +1.240306D^{-0.279878}\\
&+0.356807(1-Q_B)^{0.991543}N^{-0.162073}
 +\lambda_p\Delta_p(\mathbf p),\\
\Delta_p(\mathbf p)={}&\overline f_{\rm P1,V2}(\mathbf p)-\overline f_{\rm P1,V2}(\mathbf p_0).
\end{aligned}
\]

$N,D$ 在本式中分别以**十亿参数、十亿 Token**计量；$\overline f$ 为 P1 V2 对 13 个验证域 Loss 的均值，$\mathbf p_0$ 为固定参考配比。只有同时令 $Q_B=1$ 且 $\mathbf p=\mathbf p_0$，本式才严格退化为经典 $N$–$D$ 律。$\lambda_p=1$ 是默认情景，**不是**由 A、B 联合实验估出的跨规模系数。$Q_A$ 与 $Q_B$ 没有共同锚点，不可在论文中共用一个无下标的 $Q$ 或把 P1 分数直接塞入 B6 质量项。

**证据与反例段。** B1 留参数规模组 RMSE 为 **0.000151**，但其训练轨迹属于统一 Pythia 来源；对 B2、B4、B5 的零校准原始 RMSE 分别为 **1.2431、0.2927、0.1976**，显示组内精确性不能当跨源真实性。在 B6 半合成数据上，质量×N 相比加性质量项的留 N 组 RMSE 由 **0.08144 降至 0.05235**；B7 精确新增点由 **0.05952 降至 0.04213**。B8 精确新增点仍为 **1.34176**。B6/B8 有 **160** 个完全相同 $(N,D,Q_B)$ 输入却对应不同 Loss；B8−B6 的平均差 **−1.15361**，且 Q=0.1 与 1.0 时平均差分别为 **−2.158315、−0.01252**。在固定 $(N,D)$ 组内，B6 的 45 组 Q–Loss 斜率全负，B8 的 150 组全非负。若对这 160 对标签等权，任何不读取来源标签的确定性函数 $L(N,D,Q_B)$ 的理论 RMSE 下界为 **0.69768**：

\[
\mathrm{RMSE}_{\min}=\frac12\sqrt{\frac1{160}\sum_{i=1}^{160}(L_{6i}-L_{8i})^2}.
\]

这是模型结构无法越过的数据冲突，不宜用“质量越高必然降低 Loss”的统一规律表述。

**模型选择段。** 第二轮候选 $Q\times N\times D$ 在 B6 留 N 组仅把 RMSE **0.052346→0.051061**，B7 新点 **0.042127→0.041167** 且配对区间跨零，B8 略退至 **1.342263**，故只列敏感性。B8 来源适配确实能在**已取得 B8 目标标签**后显著降低同源留出误差：200 校准/1280 测试协议下，零样本 Model C **1.3351**、同标签预算截距校准 **0.7517**、含 Q 交互适配 **0.1336**。这应置于“有标签来源适配”小节或附录，不能写成 Model C 零样本跨源预测，亦不能把 B8 的估算行当现实大模型实测；该适配没有传入 P3/P4。

**边际与等价条件。** 固定 $D,\mathbf p$ 且 $0\le Q_B<1$ 时，质量与参数的边际导数分别为

\[
\frac{\partial L}{\partial Q_B}=-0.356807(0.991543)(1-Q_B)^{-0.008457}N^{-0.162073},\qquad
\frac{\partial L}{\partial N}=-0.353980(0.339977)N^{-1.339977}
-0.356807(0.162073)(1-Q_B)^{0.991543}N^{-1.162073}.
\]

“质量提高 0.1 等价于参数增加多少”应定义为同一 $D,\mathbf p$ 下的数值方程 $L(N_{eq},D,Q_B,\mathbf p)=L(N,D,Q_B+0.1,\mathbf p)$，并仅在 $0\le Q_B\le0.9$ 内求解。B6 条件模型在 $D=300$（即 300B Token）、$Q_B:0.6\to0.7$ 时，7B 的倍数约 **1.414**；70B 的 **1.614** 已超出 B1 最高约 12B 的支持域，必须标敏感性。P1 V2 在既定 1M/60M/1B 测试的中心化配比幅度斜率为 **0.822/0.609/0.182**，是已查看标签上的回顾性诊断，不是可代入 $\lambda_p(N)$ 的已验证函数。

**问题二摘要可用一句。** “经典 $N$–$D$ 律保留为同族主基线，B6/B7 半合成机制支持质量×规模的条件表达；B2 的跨源偏移与 B8 同点冲突共同限定了零样本广义标度律的适用范围。”

## 容易失分的矛盾、引用与终稿核查

1. **版本。** 两份旧参考报告称“问题一最终只有 V2”；现在 V3 是 1M 条件候选，但 P2/P3 依旧嵌入 V2。`problem2_v2/problem2_v2_report.md` 后部旧问答第 16 条称“最终 V2 缺跨尺度逐配方预测”，与同文件前面的新 V2 幅度表矛盾；合稿只用新表 `p_scale_transfer_from_problem1_v2.csv` 的**回顾性**口径。V3 的 1B 坏结果不能省略。
2. **证据性质。** 272,505 是记录行数，A1 与 A2/A3 重合 1,419/10,000 ID，不能称全都独立。A12–A15、B10 属估算/外推；B6–B8 是半合成。B2 来源偏移、B8 反向机制和 V3 1B 退步都应与优势同图同表。
3. **公式。** “$Q_B=1$ 退化经典律”须附 $\mathbf p=\mathbf p_0$；否则配比项尚在。$N,D$ 进入 P2 式时用十亿单位，进入 P3 的 FLOPs 成本时恢复原始参数/Token 数。$Q_A$ 与 $Q_B$ 两量尺、主 Model C 与有标签 Model B/B8 适配必须区分。
4. **参考文献。** 赛题 Markdown 与《数据说明》把 RegMix 写为“ICML 2024”，[正式 ICLR 2025 会议页](https://proceedings.iclr.cc/paper_files/paper/2025/hash/5f67d864aae6115374fed7beddd119e0-Abstract-Conference.html)确认 Liu 等的正式出处是 **ICLR 2025**。组合数据对数比可引 [Aitchison, JRSS B 1982, 44(2):139–160](https://academic.oup.com/jrsssb/article/44/2/139/7027742)；经典计算最优背景可引 [Hoffmann 等, NeurIPS 2022 正式会议页](https://papers.nips.cc/paper_files/paper/2022/hash/c1e2faff6f588870935f114ebe04a3e5-Abstract-Conference.html)；B1 同源性质可引 [Biderman 等, ICML 2023](https://proceedings.mlr.press/v202/biderman23a.html)。这些文献只支撑方法动机和数据来源，项目数值仍须引项目附件与结果表。Hoffmann 正式会议条目标题为 *An empirical analysis of compute-optimal large language model training*，PDF/预印本标题可不同，参考文献应统一按所引版本填写。

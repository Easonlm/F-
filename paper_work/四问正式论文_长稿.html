摘要

大语言模型训练资源配置涉及参数规模、训练数据量、语料质量和领域配比的联合决策，而各因素的数据来源及观测尺度并不一致。针对将单尺度配比响应直接用于大规模训练、将半合成质量关系直接解释为通用规律等建模挑战，本文建立“质量与配比评价—条件标度律—预算优化—能力前沿检验”的分层框架。首先，对 272,505 条文本信号记录构造四组等权的质量代理，并以 512 个配方实验训练 17 域组成回归模型。所选二阶 ALR 多任务 ElasticNet 在既定 1M 配方集上的 pooled RMSE 为 0.2543，较二阶 ALR Ridge 的 0.2702 降低 5.86%；在 1B 集上由 2.7021 降至 2.6887。其次，基于 B1 的参数–数据标度律和 B6 的质量条件项建立损失函数；相较加性质量项，质量与参数规模交互使 B6 留参数组 RMSE 从 0.08144 降至 0.05235。将该函数接入训练、质量处理及上下文成本后，在 102410^{24} FLOPs、三倍观测上界情景下，得到 N=35.897N=35.897 B、D=899.68D=899.68 B、QB=1Q_B=1，条件预测 Loss 为 1.9794。最后，以 45 个严格匹配的开放权重模型构造六基准能力指数，建立家族分组验证 RMSE 为 11.864 分的单调桥接，并报告固定于 2025-01-31 原点的能力情景。结果表明，分层建模能够给出可复核的配置剖面；跨质量量尺、跨规模配比效应和长期能力数值仍需结合相应观测条件解释。

关键词： 大语言模型；数据质量；组成回归；标度律；算力约束；能力前沿

1 引言

有限算力下的预训练配置需要同时决定模型参数量 NN、训练 Token 数 DD、数据质量 QQ 及领域配比 𝐩\mathbf p。经典标度律描述 NN 与 DD 对验证损失的影响[4]；数据筛选与配比研究进一步提示训练语料结构的重要性[2,3,6]。然而，本题的质量信号、配方试验、标度样本和开放模型历史记录分别来自 A、B、C 三组附件。它们的损失口径、质量量尺及规模支持范围不同，因此需要将可估计的模块与条件连接明确区分。

本文以验证 Loss 为前三问的目标量，以六项 Benchmark 均值为第四问的能力量。先在 A 组定义文本质量代理并学习配比响应，再在 B 组估计条件损失函数，以题设成本求解资源配置，最后用 C 组检验 Loss–能力桥接及历史前沿。对于未共同观测的 QA↔QBQ_A\leftrightarrow Q_B 与配比跨规模幅度 λp\lambda_p，仅设置显式情景，不将其作为已估计参数。

本文贡献概括为三点：

  1. 建立可追溯的质量与配比评价。 对 A1–A3 共 272,505 条信号记录使用固定的四组等权质量规则；在 A6/A7 的 1M 配方集上，二阶 ALR 多任务 ElasticNet 相比二阶 ALR Ridge 的 pooled RMSE 降低 5.86%，同时保留可用于下游的组成数据差分接口。
  2. 构建条件质量标度律与预算配置模型。 在 B6 留参数组上，QB×NQ_B\times N 项相比加性质量项将 RMSE 降低约 35.7%；在 101910^{19}、102210^{22}、102410^{24} FLOPs 下给出观测域、三倍边界及自由外推的配置剖面，并核对预算与最优性条件。
  3. 建立能力口径与跨问证据链。 对 45 个严格匹配的开放权重模型计算六基准能力指数；C6 的 Loss–能力桥接在家族分组验证中 RMSE 为 11.864 分，并对历史前沿与 12/24 个月情景分别标明样本条件和预测原点。

1.1 相关研究与本文定位

参数量与训练数据量之间的配置关系是预训练资源分配的基础。Hoffmann 等[4]通过规模实验讨论给定计算预算下的参数和数据选择，Pythia 工作[5]为同一模型族的训练轨迹分析提供了公开样本。此类研究支持用低维幂律刻画规模效应，但具体系数依赖语料、模型族和验证损失口径。本文因而只用 B1 估计统一的 NN–DD 主项，并将 B2/B4/B5 作为未经校准的跨来源比较；组内误差和组外误差分别报告，避免把同一训练轨迹上的精细拟合直接解释为跨族精度。

数据维度同时包含样本质量与领域组成。DataComp-LM[2]强调数据集设计对语言模型训练的重要性；RegMix[3]与 Data Mixing Laws[6]提示小规模配比实验可为候选训练配方提供预测信息。本文的 A 组质量信号与配比 Loss 并不构成“质量筛选—模型再训练”的成对实验，因此四组等权 QAQ_A 是可审计的筛选代理，而非已校准的性能收益。另一方面，17 域占比之和为一，改变一个领域必然改变其他领域；对数比坐标[1]用于表达这种相对结构。与直接把 17 个比例独立输入回归相比，该参数化更符合配方数据的几何约束，并允许在固定参考配方下输出可比较的 Loss 差分。

从预训练损失到下游能力还需定义统一的测量对象。已有研究讨论训练量与任务表现的关系[7]，算法进展研究[8]则为规模之外的时间项提供了分析动机。本题 C 组记录包含不同能力任务、发布时间及开放权重口径，不能用单一分数替代全部任务表现。因此本文先固定六项基准的等权能力定义，再以 C8 逐任务记录检查一致性，并对 C6 桥接使用模型家族隔离评价。未来能力只作为冻结原点下的条件情景表达，确保历史回顾与当下预测在时间含义上清楚区分。

2 数据、符号与研究设计

A1–A3 含文本质量信号；A4/A5 提供 512 个 1M 配方及 13 个验证域 Loss，既定 1M、60M、1B 配方集用于回顾性评价。B1 含 1,176 条参数–数据规模轨迹；B6/B7 提供半合成质量响应；C1、C4、C6、C8 分别用于能力记录、算力元数据、Loss–Benchmark 桥接和逐任务核对。A、B、C 并非同一批联合控制训练，本文据此采用分层估计。

3 方法

3.1 文本质量代理与组成配比模型

依据指标语义，将 22 项文本信号映射为教育价值、可读性、洁净度和结构四组效用。分位点及长尾变换固定在 A1 上；高度相关的三项 DSIR 信号先合并为教育组中的一个子维度。对文本 jj 定义

QA,j=14∑g=141|Ig|∑k∈Iguk(xjk),QA,d=meanj∈dQA,j.Q_{A,j}=\frac14\sum_{g=1}^{4}\frac1{|I_g|}\sum_{k\in I_g}u_k(x_{jk}),\qquad Q_{A,d}=\operatorname{mean}_{j\in d}Q_{A,j}.

组间等权使每个概念组对总分贡献相同。若同一文本至少一组评分处于 A1 上四分位、同时至少一组处于下四分位，则标记为组间冲突。冲突标记用于定位复核样本，不改变主质量分。

配比具有闭合约束，采用对数比坐标[1]。以 pile_cc 为参照域、ϵ=0.000249500998\epsilon=0.000249500998 为零替换量，令

xi=logpi+ϵpr+ϵ,i≠r.x_i=\log\frac{p_i+\epsilon}{p_r+\epsilon},\quad i\ne r.

由 16 个一次项、16 个平方项和 120 个两两交互项组成 ϕ(𝐱)\phi(\mathbf x)，对 13 个验证域联合拟合多任务 ElasticNet：

minB,b∥Y−1b⊤−ΦB∥F22n+αρ∥B∥2,1+α(1−ρ)2∥B∥F2.\min_{B,b}\frac{\|Y-\mathbf1b^\top-\Phi B\|_F^2}{2n}+\alpha\rho\|B\|_{2,1}+\frac{\alpha(1-\rho)}2\|B\|_F^2.

最终规格为 α=0.01\alpha=0.01、ρ=0.7\rho=0.7。联合收缩用于共享验证域间的配比特征；下游仅采用相对参考配方 𝐩0\mathbf p_0 的预测差 Δp(𝐩)=fA(𝐩)−fA(𝐩0)\Delta_p(\mathbf p)=f_A(\mathbf p)-f_A(\mathbf p_0)。

3.4 能力指数与桥接

主口径要求 C4 中明确开放权重、模型与发布方直接匹配，并在 C1 中具有 IFEval、BBH、MATH Lvl 5、GPQA、MUSR、MMLU-PRO 六项完整得分。定义 SS 为六项 0–100 分的等权均值，季度前沿为严格样本的 p95p_{95}。参考下游任务随训练变化的研究动机[7]，C6 使用高可比权重 1、中可比权重 0.35 拟合单调有界 logistic Loss–能力桥接，并按家族分组评估。历史对照分别拟合仅算力模型与算力加时间模型；技术时间项的讨论参考算法进展研究[8]，12/24 个月结果采用明确的算力增长和时间项情景。

第一阶段：经典 N–D Scaling Law

模型、估计与代码

经典式 LND=E+AN−α+BD−βL_{ND}=E+AN^{-\alpha}+BD^{-\beta} 与 Chinchilla 一类加性幂律模型一致，允许分别识别参数与 token 的边际衰减。V1 run_problem2.py:fit_classic 对 B1 做 SciPy least_squares，直接估计正参数，界为 E∈[0,4]E\in[0,4]、A,B∈[10−5,100]A,B\in[10^{-5},100]、α,β∈[0.005,2]\alpha,\beta\in[0.005,2]；四组初值择残差平方和最小者。它不是“对全部参数取对数再优化”。V2 models.py:fit_nd 用同样有界残差拟合候选，并保存 nd_fit_comparison.csv。V1 classical_scaling_params.csv 的多初值最大差均约 10−1110^{-11}，说明同一 B1 目标上的数值收敛稳定。

数学模型与计算链的进一步说明

A. 逐任务能力

同一叶任务只使用预先固定的评价指标：BBH、GPQA、MUSR 为 acc_norm,none，MATH 为 exact_match,none，IFEval 为 inst_level_strict_acc,none，MMLU-Pro 为 acc,none。先在相同 task/metric 内计算百分位 r_ij，再令 DetailedAbility_i=mean_j r_ij、WeakAbility_i=Q25_j r_ij。父任务与子任务不重复计数；至少50%任务覆盖与三个任务族。百分位是样本相对指标，不能与榜单0–100原始分直接减法比较。用同模型的相关性和名次差检查它是否支持六维主指标。

B. 桥接模型

模型族分组折中，同一系列绝不同时出现在训练与测试。线性桥接为 S=a+bL, b<=0；有界桥接为 S=100 sigmoid(a+bL), b<0；isotonic 为单调非增的经验阶梯函数，在训练Loss范围外为常数。主报告选择有界桥接以保证预测量纲与0–100边界，并以分组CV报告其泛化误差。High-only样本集中于少数系列，不能把其拟合优度看成跨模型族性能。C5只作对照，不增补C6主表。

C. 规模与剩余时间趋势

主回归在验证过的独立发布上为 Y_i=beta0+betaC(log10(C_i)-23)+betaT*t_i+error_i，Y_i=logit(S_i/100)，t 以2024-01-01起算年数。训练算力来自C4 reported FLOP；C4的N、D用于参数冲突检查、proxy和 Y~log10(N)+log10(D)+t 替代模型。独立发布去重避免一次模型多次提交扩大样本量。用组织分组CV检查拟合。由于时间与算力同时变化，betaT还包含未观测数据质量、后训练、评测适配与样本选择；它不是特定算法的因果效应。

D. 对称反事实分解

以历史首季度观测p95能力为 S00，把算力从首季p90切到末季p90、把时间从首季切到末季，构造 S10、S01、S11。算力贡献为 [(S10-S00)+(S11-S01)]/2；剩余时间贡献为 [(S01-S00)+(S11-S10)]/2。两者精确加到 S11-S00。组织聚类bootstrap重拟合回归，再逐次分解。模型隐含变化与实际 p95 变化方向相反的诊断被保留；这比只报告模型内百分比更重要。等效算力倍数为 10^(betaT*Δt/betaC)，仅在 betaC>0 时解释。

E. 未来情景

C4开放语言模型季度p90算力序列作为外生资源路径；排除不完整季度。其2023–24对数年斜率记为g。未来第h年资源为 C_h=C_0*exp(g*h*scale_factor)，scale_factor 为1、0.5、0.25。技术残差 betaT*h*tech_factor，tech_factor 为1、0.5、0。能力预测在最后观测p95的 logit 上累加两项再反变换。组织bootstrap的系数分布加历史残差形成条件区间；不同情景形成包络，与条件区间概念不同。因为历史开源能力前沿只有四季，12/24个月滚动原点没有可用折，表中的长期数值不可视作已校准预测。

F. 问题一至三的机制链

读取问题二 V2 的 Model C 参数与问题三 V2 的求解函数，在给定C下得到E0、E1、E2的N、D、Q和 Loss。问题一的P1观测支持域配比通过问题三V2已审计的 delta_p 传入；主对照采用P0参考配比，P1仅作lambda=0.25敏感性。再将Loss输入C6桥接。E1的3倍N/D上限在所有未来算力情景中都被触及，所以E1出现平坦的机理预测；这揭示的是机制约束与外推范围，而非前沿必定停滞。C6分组CV误差带和强外推标记与机制结果一同输出。

规模/技术贡献分解

以首末季度 p95 为锚，对固定算力和固定时间两条路径作对称 Shapley。模型隐含总变化 6.84 分，其中算力 2.15 分（31.5%）、剩余时间项 4.69 分（68.5%）；组织 cluster bootstrap 95% 区间分别 [1.09,2.96] 和 [-5.93,43.44]。实际观测 p95 变化 -2.80 分，与模型隐含方向不一致，因此不能把上述百分比当作稳健主结论或因果份额。 历史不满12个月，最近12/24个月贡献无法计算。技术等效算力由 10^(betaT Δt/betaC) 求出，仅作为敏感性。

11 讨论与结论

本文建立了从质量代理、配比响应和条件标度律到预算决策与能力情景的可追溯链条。配比模型在既定 1M 集上取得 5.86% 的 pooled RMSE 降幅；质量与规模交互在 B6 留参数组上取得约 35.7% 的 RMSE 降幅。预算模型进一步表明，高预算条件配置对 N,DN,D 上界和质量成本形式敏感，因而应同时报告观测域、扩展边界与自由外推的剖面。开放模型分析提供统一的六基准能力口径，并将桥接误差与情景范围并列呈现。

当前结论聚焦于附件给定的质量量尺、配方支持域和严格开放权重样本。未来可通过人工质量盲评、同一模型族内的配比与质量受控训练，以及更长时间跨度的同口径能力记录，进一步校准跨数据源连接和能力情景。

领域配比 𝐩\mathbf p 如何加入问题二

定义问题一模型给出的 13 验证领域平均预测 Loss 为 L‾p(𝐩)\bar L_p(\mathbf p)，再中心化：

Δp(𝐩)=L‾p(𝐩)−L‾p(𝐩0),𝐩0=(1/17,…,1/17).\Delta_p(\mathbf p)=\bar L_p(\mathbf p)-\bar L_p(\mathbf p_0),\qquad\mathbf p_0=(1/17,\ldots,1/17).

最终附加 λpΔp\lambda_p\Delta_p。中心化使参考配比的修正为零，避免把问题一的绝对预测截距误搬到 B1 的 Loss 标尺；局部两配比的差分也不依赖参考常数。λp\lambda_p 是跨数据来源/规模的幅度桥接系数，当前 B 数据没有共同的 (N,D,Q,𝐩)(N,D,Q,\mathbf p) 实验来估它；代码中取 1 为基准情景，并做 0.5、0.75、1、1.25、1.5 敏感性，见 bridge_assumptions.json 和 sensitivity_summary.csv。V2 的 p_scale_scenarios.csv 另给常数、N−0.1N^{-0.1}、N0.1N^{0.1} 三种未识别情景，不能把它们当拟合结果。乘法桥接只在 model_candidates.md 提为候选/情景，项目没有证明比加性桥接更好。

证据等级与结论

三种质量成本是同等级题设情景：中高预算 Q 饱和是跨情景共识；低预算质量投资高度依赖成本假设。联合参数 bootstrap 区间很窄，主要反映 B1 在固定经典公式下近乎确定性的轨迹，不能解释为现实模型参数或跨数据源误差也同样小。它不覆盖成本函数、Q0、C7 元数据与 B8 外部来源失配。跨场景共识区间才用于展示这些结构性假设的变化。

长上下文使同样 N-D 的成本增加，主情景下反而让相对便宜的 Q 更早值得投资：指数成本的起投点从 2048 tokens 的约 3.90×10^18 降到 32768 tokens 的约 2.21×10^18；这是给定成本结构与 Model C 的替代效应，不是通用规律。对数成本的起投与饱和同点，表示最优 Q 出现离散跳跃，不能把它解释为渐进质量投资阶段。

10^24 下 E1 的 N 与 D 同时碰到 3× 上界，全部 36 个场景在此角点共享同一个最优解，所以 minimax regret=0；这是一种边界驱动的退化结果，不是高预算风险已被消除。软罚解在 ω=.01–1 下仍达到 N≈60–75B、D≈1.9–2.4T，与 E1 的 N≈35.9B、D≈0.90T 相距明显，软罚并未独立支持 3× 推荐。E1 缓和强外推，却不能升级为实证解；预算仍有大量未使用。

论文主文应采用 V2 的跨情景共识与 E0/E1/E2 三层对照；单一 λp=1 收益、精确结构点及 E2 高预算 Loss 只作为条件情景结果。

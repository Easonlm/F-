# 问题三：新风险目标的复验

## 候选与协议

在原有 E1（B1 观测上界的 3 倍）与 36 个训练情景下，新增两种资源配置策略：最小化**平均后悔值**、最小化**最差 10% 情景的平均后悔值（CVaR90）**。与既有最小化最大后悔值、修复到共同可行域的名义方案比较。四种策略均须对三种质量成本、两个初始质量和两个上下文长度共同可行。每个情景的后悔值等于该策略的 Model C Loss 减去该情景单独优化的 Loss。

训练集使用 V2 既定的 3 个联合参数 bootstrap 向量 × 12 个结构情景，共 36 个。固定种子从其余参数 bootstrap 向量抽 12 个，组合相同 12 种结构情景，形成每预算 144 个参数留出情景；为其各自重算条件最优值。比较预算为 $10^{19}$、$10^{22}$、$10^{24}$ FLOPs。代码 [`evaluate_policies.py`](evaluate_policies.py) 生成 [`policies.csv`](policies.csv)、[`policy_summary.csv`](policy_summary.csv)、[`scenario_policy_scores.csv`](scenario_policy_scores.csv) 与 [`run_metadata.json`](run_metadata.json)。

| | 新 CVaR90 | 0.166280 | 0.322383 | 0.335892 | 100% |
| | 修复名义 | 0.172389 | 0.328467 | 0.342099 | 100% |

| | 新 mean | 0.027045 | 0.055234 | 0.056130 | 100% |
| | 新 CVaR90 | 0.027045 | 0.055234 | 0.056130 | 100% |

| $10^{24}$ | 四种策略 | 约 0 | 约 0 | 约 0 | 100% |

新策略在 $10^{19}$ 的留出平均后悔值比原 minimax **高约 $1.6\times 10^{-6}$**，在 $10^{22}$ **低约 $3\times 10^{-9}$**；其配置也几乎相同。$10^{24}$ 下四者均落在 3 倍上限角点，Loss 约 1.9794。数值上的细小差异没有实际优化意义。相较之下，原 minimax 在两个较低预算上都优于修复名义方案，但这属于题设结构情景内的结果。

**决策：不替换原 minimax。** 两种新风险目标提供了稳定性复核，但没有带来可辨识的性能提升。高预算的共同角点由人为上限驱动，不能据后悔值为零证明真实规模选择正确。留出参数向量仍由同一 B1/B6 原始数据重采样得到，并非独立外部样本；质量成本函数也只是题设情景，故此实验只评价当前假设下策略对参数扰动的稳健性。

复现：在项目根目录运行 `python optimization_20260924/round2/q3/evaluate_policies.py`。脚本检验训练/留出参数不重叠、每预算 144 个留出情景、所有策略可行且后悔值非负。

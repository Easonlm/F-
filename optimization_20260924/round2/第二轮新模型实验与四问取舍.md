## 各问证据与接入位置

### 问题一

新样条只用 A4/A5 的 512 个 1M 配方训练与选参，固定原 V2 的外层五折；5/5 折改进。按配方配对重抽样，V2 减 V3 的 RMSE 改善区间在 1M 为 **+0.0620 [0.0447, 0.0789]**，在 1B 为 **−0.0336 [−0.0613, −0.0073]**。因此接受 1M 条件效果，拒绝声称跨规模全面改善，也不依据已查看的 1B 标签事后设切换阈值。完整实验见 [`q1/experiment_decision.md`](q1/experiment_decision.md)，主脚本与核验见 [`problem1_v3.py`](../../problem1/problem1_v3.py)、[`problem1_v3_report.md`](../../problem1/problem1_v3_report.md)。

### 问题二

新 Q×N×D 项在 B6 留 N 组与 B7 新点上有约 2% 改善，但不能解决 B6/B8 对相同输入的质量方向冲突，故不替换零样本 Model C。有标签 B8 来源适配则回答不同问题：从目标来源提供 200/1480 条 B8 新记录作校准，在不重叠的 120 个 N–D 单元、1280 条记录上，交互校正 RMSE **0.13357**，同等标签预算的截距校正 **0.75167**。更严格地让校准与测试的 Q 水平也完全不重合，102 条校准、728 条测试时分别为 **0.12789** 和 **0.78042**。这些数字不能与完全不使用 B8 标签的模型作为同一信息预算的竞赛。

B8 中 `extrapolated` 类型是附件中的估算标签；用 56 条 `calibrated` 记录校准后测试 720 条该类型记录，交互校正 RMSE **0.18579**，截距校正 **0.69872**，仅说明对附件标签的条件预测。适配接口 [`source_quality_calibration.py`](../../problem2_v2/source_quality_calibration.py) 显式要求校准与评估 ID，并禁止相同记录或 N–D 单元同时出现在两侧；默认主 artifact 与 P3/P4 使用的八参数 Model C 不变。独立实验、分层、重抽样和消融见 [`q2/report.md`](q2/report.md)。

校准设计本身有门槛：每个 N 只有 1 个 D 单元时，100 条校准标签下完整交互式在 1380 条留出记录上的 RMSE 为 **0.7550**，截距校正 **0.7608**，几乎无增益；该结构被正式接口拒绝。较简单的 **Q-only** 残差校正以相同 100 条标签达到 **0.2387**；再同时留出全部测试 Q 水平与 N–D 单元，51 条校准、777 条测试时，Q-only 为 **0.2207**，同预算截距为 **0.8080**。因此接口新增显式 `q_only` 低标签模式，默认完整交互仍要求每个校准 N 至少两个 D 锚点。两种校准设计的分数不能直接当作同一任务排名。问题二主报告的 [B8 有标签来源校准补充](../../problem2_v2/source_quality_calibration_addendum.md)列出各协议与标签成本。

### 问题三

采用 3 个训练参数向量×12 个成本/质量/上下文情景，并从未用于训练的联合 bootstrap 向量抽 12 个形成每预算 144 个参数留出情景。所有策略必须同时满足全部成本情景。新 mean/CVaR90 与既有 minimax 配置几乎重合；$10^{19}$ 的留出平均后悔值差仅约 $1.6\times10^{-6}$，$10^{22}$ 差约 $-3\times10^{-9}$。$10^{24}$ 时共同角点来自 3× 假设边界，不是模型成功外推的证据。代码、逐情景损失及决定见 [`q3/实验评估与取舍.md`](q3/实验评估与取舍.md)。

### 问题四

新桥接使用相同 C6 五折家族组外划分。最好的自由 Loss+规模候选 RMSE 10.560，对照为 11.864，但 Loss 斜率在 5 折的 4 折接近零，规模单变量诊断还达到 10.451；它不构成可靠的 Loss→能力桥接升级。其他候选的配对家族重抽样改善区间均跨零。完整比较见 [`q4/新结构候选实验.md`](q4/新结构候选实验.md)。

持平前沿作为无未来信息的短期朴素基线已加入问题四主流程的 [`short_term_baseline_comparison.csv`](../../problem4/outputs/tables/short_term_baseline_comparison.csv)。同原点的 3 月两个目标，直接时间趋势 MAE 6.48，持平 3.95；6 月仅一个目标。目标季度达到 $n\ge5$ 后，总共只有一个可用回测点，故主 12/24 月预测仍是情景结果。

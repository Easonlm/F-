# 问题四第二轮：C6 桥接的新结构候选

本轮只测试新模型，不改 `problem4/` 的主桥接或预测。复现命令（项目根目录）：

```powershell
python optimization_20260924/round2/q4/run_new_models.py
```

代码、逐行组外预测、每折参数和结果均在本目录。`metadata.json` 记录输入 SHA-256 和断言：原 weighted logistic 的五折 RMSE 与既有 `loss_benchmark_bridge_cv.csv` 逐折相同；每折训练/测试家族不交叠。

## 1. 数据与判别目标

C6 完整样本为 **75 行、23 个模型家族**；验证损失 `Val_Loss`、能力分数和参数量 `N_params_B` 均有 75 行，训练 token `D_tokens_B` 只有 **7 行**，因而这轮不加 D。高可比损失仅 **7 行、1 个家族**，其余 68 行损失来自不同验证集。现有有界 logistic 按高/中可比性赋权 1/0.35，五折家族组外 RMSE **11.864 分**。

实验条件锁定为原有 `GroupKFold(5)` 与相同训练权重。所有自由参数仅在各训练折拟合，折点仅由该折 Loss 中位数确定。目标是考察新结构能否在**同一测试行**稳健降低误差，同时仍是可解释的 Loss→能力桥接。单个好看的训练误差不算升级依据。

## 2. 新结构与结果

| 结构 | 改动 | 组外 RMSE | 相对原模型改善 | 家族配对重采样改善 95% 区间 | 决策 |
|---|---|---:|---:|---:|---|
| 原有 bounded logistic | (100\sigma(a-bL)) | 11.864 | 0 | — | 保留主桥接 |
| 单调折点 logistic | 在训练 Loss 中位数两侧分别估计正斜率，曲线连续且有界 | 11.849 | +0.015 | [−0.464, +0.414] | 拒绝升级 |
| Gompertz | (100\exp[-\exp(a+bL)])，非对称有界单调曲线 | 11.769 | +0.096 | [−0.034, +0.384] | 拒绝升级 |
| 固定 Loss 斜率、增加规模校正 | 先在训练折拟合原 logistic，保持其 Loss 斜率，再估计 `log10(N/10B)` 修正 | 11.576 | +0.288 | [−0.489, +0.980] | 拒绝升级 |
| 自由 Loss + 规模桥接 | 同时估计正 Loss 斜率与规模效应 | 10.560 | +1.304 | [−0.805, +2.782] | 仅作诊断，不替换主桥接 |
| 仅规模诊断 | 不使用 Loss，只用参数量 | **10.451** | +1.413 | [−0.904, +2.884] | 不是 Loss 桥接，不作主模型 |

改善区间以 **23 个家族**为单位对同一折的组外残差配对重采样 5000 次；它衡量样本家族构成对差异的影响，并未在每次重采样内重新训练。所有候选在固定参数量时给出 0–100、有界且随 Loss 不增的预测，诊断用仅规模模型在固定规模时为平线。每折指标与外推支持域计数见 `fold_metrics.csv`。

## 3. 为什么规模模型的低误差暂不能保留

自由 Loss + 规模模型虽在五个组外折的 RMSE 均较原模型低，但其 Loss 斜率在 **5 折中的 4 折**达到优化器下界 (e^{-8}=0.000335)，全样本拟合也为 **0.000335**；仅规模模型的 RMSE 还低 **0.109 分**。这表明该数据里组外改善几乎由参数量承担，而非模型学到了更可迁移的 Loss→能力关系。C6 中 Loss 与 `log10(N)` 的描述性相关为 **−0.856**，且绝大多数 Loss 跨验证集，二者的独立贡献难以识别。

规模校正的五折系数均为正，确有可重复的方向；但固定原 Loss 斜率后，改善仅 **0.288 分**，家族重采样区间仍跨零。原 logistic 的五折 RMSE 范围 **7.265–16.565 分**，折间标准差 **3.583 分**；固定斜率候选的增益小于这个变动。高可比 7 行只来自一个家族，也无法对该层做独立家族验证。

**取舍：** 继续使用原 weighted bounded logistic，并沿用约 11.9 分组外误差与机制预测的情景性质。单调折点、Gompertz、固定斜率规模校正均没有跨家族稳定改善；自由规模模型作为“当前 C6 中 Loss 效应可能被规模替代”的辨识诊断保留在本实验记录，不进入主 P4 机制链。

进一步升级需要：更多使用同一验证损失定义、覆盖多个独立家族且有参数量与训练 token 的观测；在预先锁定的家族外测试中，新增结构需保留非退化的 Loss 斜率，并让改善区间下界大于零。当前 75 行混合可比性数据尚不足以支持该升级。

## 4. 不使用未来信息的短期前沿候选

额外脚本 `run_short_term.py` 只读取现有 `quarterly_frontier.csv` 和 `forecast_backtest.csv`。它在原有严格 W1 的**相同预测原点和目标季度**重算 `direct_time`，逐行预测与原回测相同；然后比较两个事先固定的候选：将原 logit 趋势斜率乘 0.5 的半速阻尼，以及将斜率设为 0 的持平预测。所有斜率只由预测原点及其以前的季度计算。

| 目标季度 | 目标 n | 原直接时间趋势绝对误差 | 半速阻尼 | 持平 |
|---|---:|---:|---:|---:|
| 2024Q4，提前 1 季 | 5 | 11.106 | 8.392 | **5.732** |
| 2025Q1，提前 1 季 | 2 | **1.847** | 2.004 | 2.162 |
| 2025Q1，提前 2 季 | 2 | 18.800 | 13.268 | **7.894** |

全部 2 个三月目标的 MAE：原趋势 **6.477**，半速阻尼 **5.198**，持平 **3.947**。但按最低目标样本数 n≥5 后只剩 **1 个三月目标、0 个六月目标**。这一点仅说明以两个点外推趋势在现有序列上风险很大，不能证明持平模型可迁移。**保留持平作为短期朴素基线和风险参照，不替换 12/24 个月的条件情景；半速阻尼仅留实验记录。** 原现有直接回测也没有 12/24 个月目标，因此这组误差不能充当长期预测改善证据。

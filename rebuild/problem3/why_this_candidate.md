# 问题三决策规则：预先登记的复赛协议

## 当前缺陷和数据依据

当前 P3 V2 用 B1 实测 N、D 上界的 3 倍定义 E1，再在 36 个题设/参数情景内最小化最大后悔值。`problem3_v2/outputs/tables/cap_sensitivity_profile.csv` 显示，在 10^24 FLOPs，1×/2×/3×/5×/free 的条件 Loss 分别为 2.0934/2.0171/1.9794/1.9381/1.9160，且 3× 方案只用约 22.4% 预算。上限位置显著改变结论。`robust_optimization.csv` 中 3× minimax 在此预算的零后悔值，是 36 个情景都被同一个角点限制住；不能解释为上限被数据验证。历史 round2 只在 3× 比较 mean/CVaR，尚未做跨上限、同口径的完整复赛。

## 候选与机制

沿用完全相同的 Model C 和成本核算，挑战的是政策规则：

1. 实测支持域 1×；信赖域 2×、3×、5×；及无扩展上限的 free，分别限制 N 和 D。这里的“信赖域”是应用时对外推的硬约束，**不是数值优化算法的 trust-region 收敛保证，也不是实证置信区间**。
2. 在每个上限内比较名义 Model C 的共同可行域最优、最小最大后悔值、平衡情景平均后悔值、最差 10% 情景平均后悔值、最差情景 Loss。平均/CVaR 的等权仅是实验设计，不代表现实发生概率或可识别的期望。
3. 所有政策在三种质量成本、Q0∈{0.2,0.8}、上下文∈{2048,32768} 下共同可行；每个情景单独求上限内 oracle，也另求 free oracle。前者比较相同上限内的规则，后者展示跨上限的条件机会损失。
4. 训练情景固定为联合 bootstrap 中按 G 的 5%/50%/95% 顺位选出的 3 个**完整参数向量** × 12 个结构情景；留出参数为其余向量中用固定种子抽出的 12 个 × 相同结构情景。预算固定 10^19、10^22、10^24 FLOPs。每个 oracle 在本轮重新求解；留出参数不参与政策拟合。

## 预先评价及升级门槛

主要指标按顺序是：全情景成本/质量/域约束可行、上限内及 free oracle 的情景后悔值、名义 Loss、预算使用和 N/D 外推倍数。数值诊断包括重算 oracle 的预算和边界残差、局部可行方向改进量，以及适用时的自由名义解 KKT。报告所有政策在留出情景的均值、CVaR90、最大后悔值及按参数簇配对 bootstrap 的差值。局部数值检查不伪称全局证明或平滑问题的 KKT 证书。

新政策若要替代 3× minimax，必须在共同可行域达到 100% 可行，留出主要后悔指标至少改善 0.005 Loss 且至少 5%，配对参数 bootstrap 的改进为正比例超过 90%，并且没有把唯一优势建立在更远外推上。若指标差距小于 0.005 或上限证据不足，保留简单的现有条件规则；跨上限列为 Pareto 情景，不硬选唯一生产规模。高预算上限导致预算闲置时，必须明确标注。

## 方法依据及适用边界

[Kouvelis 和 Yu 的稳健决策专著](https://link.springer.com/book/10.1007/978-1-4757-2620-6)给出无情景概率时比较后悔值的经典框架；[Bertsimas 和 Sim](https://pubsonline.informs.org/doi/10.1287/opre.1030.0065)讨论稳健性与名义性能的代价；[Rockafellar 和 Uryasev](https://www.ise.ufl.edu/uryasev/files/2011/11/CVaR1_JOR.pdf)提出尾部风险准则；[Conn、Gould、Toint](https://epubs.siam.org/doi/10.1137/1.9780898719857.ch6)解释模型只在其适用邻域内应被信任。本项目没有经过校准的情景概率或外部决策验证，因此这些文献支持候选准则的形式，**不证明任一上限或风险权重正确**。

## 上下游接口

P1 的配比效应作为与 N-D-Q 可分的 `delta_p` 项，固定配比时不改变本复赛的 N-D-Q 最优；若 P1 改为不可分桥接必须重跑。P2 的 `E,A,alpha,B,beta,G,kappa,eta_N` 直接构建 `problem3.core.Model`。若 P2 升级或联合 bootstrap 更新，必须重跑本脚本和 P4 下游，不可沿用旧 P3 结果。

# 问题三决策规则复赛报告

## 决定

**保留 P3 V2 的条件式 minimax-regret 框架；不宣布 3× 为经验证的唯一高预算上限。** 新的平均后悔、CVaR90、最差情景 Loss 目标均未达到预先登记的 0.005 Loss、5% 和外推不恶化的升级门槛。正确地在共同可行域重新优化的名义政策与 minimax 几乎等价，因此稳健目标相对名义优化的实质优势也不能夸大。高预算应发布 1×/2×/3×/5×/free 的条件式 Pareto 剖面，暂不输出唯一最优 N、D。

这项决定保留了旧模型的公式与求解结构，改进了决策证据和公正比较方法。若最终项目必须给出一个默认政策，可沿用 3× minimax 作为**明确标注的条件情景**；执行前需由应用方选择可接受的外推边界。

## 复赛口径

读取冻结的 P2 Model C 推荐 artifact、B1 观测范围和 P3 V2 联合参数 bootstrap。联合向量按 G 的 5%/50%/95% 顺位选 3 个训练参数样本，另以固定种子抽 12 个未参与拟合的参数样本。各参数向量与三种质量成本、两个 Q0、两个上下文长度相乘，得到每预算 36 个训练和 144 个留出情景。留出向量是**同一 B1/B6 数据的 bootstrap**，并非外部数据验证，情景频率亦非发生概率。

在 10^19、10^22、10^24 FLOPs 比较：B1 实测域 1×，N/D 上界 2×、3×、5×，及无扩展上限 free。每个上限内求五类政策：共同可行域名义最优、minimax regret、平衡情景平均 regret、最差 10% regret 均值、最差场景 Loss。所有政策都对 12 种结构情景共同可行。每个情景和上限的 oracle 在本次重新求解；同时以同一 free oracle 计算跨上限机会损失。脚本及全部逐情景数据在本目录。

| 10^19 | 3× | 0.30994 | 1.6315 | 0.81871 | 3.37780 | 0.166279 | 0.166279 | 0.335890 | 100% |

低、中预算的政策均落在实测域内，放宽 N/D 上限无实际作用。高预算的 1×/2×/3× 在各自域内的零后悔由上下界角点产生；对同一 free oracle 仍有显著机会损失。5× 与 free 的条件 Loss 更低，但 5× 决策的 N/D 分别是 B1 最大值的 4.41/5 倍，free 决策的 N/D 分别为 2.51/8.74 倍，不能按同等证据等级宣布升级。free 情景还含不同成本函数下的共同可行性要求，故其名义 Loss 1.93820 高于仅对指数成本/4096 上下文求的 raw nominal 1.91600。

## 风险目标与名义方案的公平比较

在 3× 上限，留出场景平均后悔值：

| 预算 FLOPs | minimax | 共同可行域名义 | 平衡均值 | CVaR90 | 最大后悔 minimax |
|---:|---:|---:|---:|---:|---:|
| 10^19 | 0.16627868 | 0.16627883 | 0.16628025 | 0.16628030 | 0.33589002 |
| 10^22 | 0.027045129 | 0.027045125 | 0.027045126 | 0.027045126 | 0.056130475 |
| 10^24 | 0 | 0 | 0 | 0 | 0 |

10^19 下 minimax 比本次公平名义方案的均值后悔仅低约 1.5×10^-7；10^22 下反而高约 3.8×10^-9。这些差值远低于预定实际意义阈值。历史 V2 的 `nominal_moderate_repaired` 在 10^19 的均值后悔约 0.172389，是先在单一场景优化再把 Q/D 截入共同可行域的**投影策略**；投影后没有重新优化 N 和 Q，因此不应代表最佳名义政策。原 minimax 对这个投影策略的优势是真实计算结果，但不足以证明 minimax 优于公正重优化的名义政策。

平衡均值和 CVaR90 使用等权场景，只能视为设计平均或尾部汇总，不能称为统计期望或已校准风险。按 12 个留出参数簇配对重采样，10^19 下均值/CVaR90 相比 3× minimax 的平均后悔分别差约 1.57×10^-6/1.62×10^-6，10^22 下改善仅 2.8×10^-9/3.0×10^-9。极窄 bootstrap 区间主要反映固定公式和同源数据，不证明现实策略性能。

## 数值与约束核验

本轮重新求解 **2700** 个情景 oracle、**75** 个政策，产生 **13500** 条逐情景评分。12 种结构情景下所有政策均可行；重新按成本公式计算的最大预算率差 4.0×10^-12；上限放宽时情景 oracle Loss 单调不增；最小计算后悔值为 -3.9×10^-11（浮点误差）；八个可行方向的最大局部目标改进为 1.6×10^-13。free raw nominal 的 KKT 相对误差最大 7.34×10^-8，Q 端点互补条件通过。minimax、CVaR 和上限活跃的政策目标可能不光滑，因此方向检查只是局部数值证据，**不是完整 KKT 或全局最优证明**。全部核验记录见 `verification_results.json`。

本轮 3× minimax 的 N、D 与冻结 V2 的同预算结果最大相对差分别为 1.2×10^-5 和 7.5×10^-6；高预算角点完全一致。这是重新求解后的数值复现，不是读取旧结果冒充本轮计算。

冻结基线清单中 P3/P3 V2 的全部 94 个文件，经本轮只读 SHA256 核对全部一致；其中 56 个是 Python、模型或表格文件。P2 推荐 Model C artifact 也与清单一致。所有新文件仅在 `rebuild/problem3/`。

## 上下游接入

入口为 `run_decision_tournament.py`，读取 P2 推荐 artifact 中的八个 Model C 参数和 P3 联合 bootstrap 表。若最终 P2 仍为 Model C，同一脚本可以对最终 artifact 重新运行并更新 SHA。若 P2 改公式，需先重写本问 Loss/梯度适配层并重新生成联合参数样本，不能把旧优化直接改名复用。若 P1 仍通过可分的 `delta_p` 传入、配比和 λp 固定，N-D-Q 决策与配比优化可分别运行；若 P1→P2 桥接使 λp 依赖 N/D/Q，必须联合优化 p。P4 只可读取最终 P3 政策和来源哈希，P1/P2 任一上游变更均使本次结果失效。

python rebuild/problem3/run_decision_tournament.py

# 问题三决策模型卡

**状态**：原 V2 Model C + 成本模型 + 条件式 minimax regret 保留，经 1×/2×/3×/5×/free 和五类政策复赛。3× 是展示用外推边界，不是被实测验证的最优边界。

**预测/决策公式**：`L=E+A N^-alpha+B D^-beta+G(1-Q)^kappa N^-eta_N+delta_p`；成本为训练、质量和注意力成本之和，单位 FLOPs。当前中心参数为 `E=1.68979756, A=0.35398032, alpha=0.33997658, B=1.24030558, beta=0.27987813, G=0.35680736, kappa=0.99154346, eta_N=0.16207292`。模型与公式来源为冻结的 `problem2_v2` 推荐 artifact 和 `problem3/core.py`。

**训练与评估**：B1 N-D、B6 Q 的同源联合 bootstrap，3 个完整参数向量 × 12 个结构情景用于政策优化；12 个不同参数向量 × 相同结构情景留出。预算 10^19/10^22/10^24；N/D 上界为 B1 实测上界的 1/2/3/5 倍及 free。预算、Q 下界、N/D 边界对所有结构情景共同可行。留出不是外部来源验证。

**主要证据**：全部 75 个政策和 2700 个情景 oracle 重算、可行性 100%、free nominal KKT 最大相对误差 7.34×10^-8。3× minimax 与共同域名义政策的后悔差远小于 0.005 门槛；其他风险目标未显示实质提升。10^24 的 3× 域内零后悔由上限角点导致，对 free oracle 留出平均后悔为 0.053511。

**超参数与概率解释**：随机种子 20260924；CVaR90 为样本最高 10% 的平均；结构情景等权用于计算平均，但没有已识别的概率。上限倍数是敏感性参数，不是置信区间。

**失效模式**：Model C 超出 B1/B6 测量范围；质量成本模型与现实不符；Q 指标未有人工真值；P1 配比作用随规模变化；上游 P2 公式更新；参数 bootstrap 因同源数据低估结构不确定性。free 下高预算资源配置特别依赖外推。

**下游接口**：输入 Model C artifact、联合参数表、B1 范围和三个预算；输出 `problem3_decision_tournament.csv`、`policies.csv`、`scenario_policy_scores.csv`、`scenario_oracles.csv`、`run_metadata.json`。下游必须校验输入 SHA，并在上游变化后重算。

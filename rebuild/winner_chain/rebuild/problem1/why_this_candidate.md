# 问题一配比模型复赛：事先固定的候选与判据

记录日期：2026-09-25。本文件在本目录的新一轮数值搜索之前写定。冻结 Champion 为 `problem1/outputs/models/mixture_v2.joblib` 的二阶 ALR Ridge；既有 V3 CLR 样条已被研究者查看，仍作为已知候选重新按同一程序比较，不视为新盲测。

## 诊断先于候选

- A4/A5 有 512 个 1M 配方、17 个组成份额、13 个验证 Loss。二阶 ALR 有 16 个一次项和 136 个二次项，每个响应有 152 个特征，名义复杂度较高。V2 的嵌套 OOF RMSE 为 0.3340，A6/A7 1M 回顾性 RMSE 为 0.2702。
- V2 在 60M、1B 实测标签的绝对 RMSE 为 1.5959、2.7021，预测减观测偏差分别为 +1.5057、+2.6186。规模外偏差占主要部分，单改配方回归不能识别规模截距或 `lambda_p(N)`。
- 已有 CLR 加性样条 V3 在嵌套 OOF 与 1M 有改善，但 1B 的 RMSE 为 2.7357，高于 V2 的 2.7021；其已看过的 A6–A11 结果不能作为新的独立检验。
- V2 的 1pp 置换有 3/16 个目标域在参考域或零替换变化后变号；系数或局部置换的稳定性需要单列。
- `manual_validation_results.csv` 为 0 行。Q 没有人工真值或独立下游标签；四组等权 Q 保留，PCA、熵权及冲突惩罚只具有敏感性地位，不能据内部拟合优劣替换 Q。

## 正式研究给出的可检验思路

- [Aitchison, *JRSS B*, 1982](https://academic.oup.com/jrsssb/article/44/2/139/7027742) 指出组成数据的闭合约束，应在对数比空间建模；[Egozcue 等，*Mathematical Geology*, 2003](https://doi.org/10.1023/A:1023818214614) 给出正交 ILR 坐标。ILR 可检验 ALR 参考域依赖，但不能消除零替换假设。
- [Zou 与 Hastie，*JRSS B*, 2005](https://doi.org/10.1111/j.1467-9868.2005.00503.x) 的 ElasticNet 可在相关的二阶特征中收缩和选择；此处只检验预测及系数稳定性，不把被选交互解释为因果作用。
- [Wold 等，*Chemometrics and Intelligent Laboratory Systems*, 2001](https://doi.org/10.1016/S0169-7439(01)00155-1) 的 PLS 适用于多响应与相关预测变量，检验 13 个 Loss 是否由少量共同轴解释。
- [Liu 等，*ICLR*, 2025，RegMix](https://proceedings.iclr.cc/paper_files/paper/2025/hash/5f67d864aae6115374fed7beddd119e0-Abstract-Conference.html) 支持小模型配比代理的研究设计，但其跨规模训练实验不能代替本题没有的跨规模拟合数据。

## 锁定候选与搜索空间

同一 5 折外层 `KFold(shuffle=True, random_state=20260924)`；每折训练部分的 3 折内层 `random_state=20260923+fold`。全部候选只用 A4/A5 训练 Loss 选型。全训练最终规格用 `RepeatedKFold(5, 2, random_state=20260923)` 的 pooled RMSE 选择。候选：

1. **V2 Champion**：复用冻结的内层胜出规格并按外折重新拟合；全训练直接加载冻结 artifact 校验指标。
2. **二阶 ALR MultiTask ElasticNet**：与全训练 V2 相同的参考域和零替换；`alpha∈{0.001,0.01,0.1}`，`l1_ratio∈{0.2,0.7}`。检验稀疏化是否减轻 152 特征的过拟合。
3. **二阶 ILR Ridge**：零替换倍数 `{0.25,0.5}`×训练最小正配比，`alpha∈{1,10,100}`。检验参考域依赖。
4. **二阶 ALR PLS**：与 V2 相同参考域和零替换，成分数 `{2,4,8,12}`；检验低秩共同响应。
5. **CLR 加性三次样条 Ridge**：零替换倍数 `{0.25,0.5}`、结点 `{4,6}`、`alpha∈{1,10,100}`，与已存在 V3 相同网格；检验低交互的平滑主效应。

所有标准化、样条结点和特征构造在每个训练折内拟合。原始 A6/A7 1M、60M、1B 标签只在选型完成后用于**回顾性**比较。10B/70B 是估算标签，只列附加诊断。已有 V2 搜索曾包含 RBF 核；本轮不再重复该高计算、高复杂度候选。Dirichlet 回归对应组成型因变量，本题因变量为实数 Loss，故不适用。

## 事先固定的胜出规则

主指标是 A6/A7 1M 的 13 响应 pooled RMSE；次指标是 MAE、13 域平均 Spearman、配方平均 Loss Spearman、同划分嵌套 OOF RMSE、60M 与 1B RMSE/偏差及排名、1pp 置换符号与模型重抽样稳定性。按照配方行进行配对 bootstrap，报告 V2 RMSE 减候选 RMSE 的条件 95% 区间。测试集曾被看过，区间**不**纠正重复选择偏差。

替换跨问 Champion 须同时满足：1M RMSE 改善且 bootstrap 区间下界大于 0；嵌套 OOF 改善或位于较简单模型的 1 SE 内；60M 与 1B 不出现显著损害（V2 减候选的配对 RMSE 区间上界不能小于 0）；13 域与配方平均排序不显著恶化；局部 1pp 效应符号至少 13/16 与 V2 一致，且数值可复现。两个候选在嵌套 OOF 均值 1 SE 内时优先选择复杂度较低、局部结论较稳的方案。若没有 Challenger 同时过门槛，V2 维持跨问 Champion；1M 专用条件模型可另外报告，但不能在未识别尺度响应时替换全链接口。

这些门槛是一次**回顾性复赛**的操作性门槛；没有新的封存配比实验时，不宣称最终模型已获前瞻性验证。

## 实现审计更正（首次运行后记录，不更改胜出门槛）

首次实现把全训练 V2 选出的 ALR 参考域带入 Challenger 的外层 CV；该参考域由全部 A4/A5 标签选出，故对外层测试折有间接信息泄漏。现改为每个外折使用冻结 V2 在**该折训练集内**所选的参考域与零替换常数，再完整重跑。全训练模型仍可合法使用全训练选出的 V2 参考域。此更正只影响嵌套 OOF，不改候选网格、A6/A7 使用规则或事先写定的升级门槛；首次外折数值作废。逐域 1B RMSE 的不利变化也将作为异质性风险单列，不能将总体 RMSE 改善表述为每个领域都改善。

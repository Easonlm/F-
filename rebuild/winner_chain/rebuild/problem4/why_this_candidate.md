# 问题四候选的预先依据与选择门槛

基线冻结于根目录 `model_baseline_manifest.json`。本目录仅写新实验产物，所有原始代码和输出均为只读输入。AUC、能力分数与 Loss 桥接的单位不同，不能混作一个 RMSE 排名。

## 残差与数据诊断

- C6 桥接只有 75 行、23 个模型家族，其中高可比 7 行且来自同一家族。原有有界 logistic 的五折家族组外 RMSE 为 11.864 分，误差远高于需要支持的精细能力点数。
- 历史结构回归 32 行、13 个组织；compute-only 组外 RMSE 7.052，compute+time 为 7.103，时间系数 bootstrap 区间穿零。原结构分解与观察的严格前沿变化方向相反。
- 严格开放前沿四季度计数为 22、16、5、2。末季单季度 p95 实际接近单模型最大值，12/24 月没有可用目标。
- C8 详细任务可用，但同六基准榜单高度相关，适合一致性而非外部真值；能力指标更复杂时不能只凭与 C8 自身的相关系数升级。

## 候选与文献依据

1. **能力指数**：现有六基准均值与标准化稳健均值、PCA 及 C8 40 项任务汇总比较。PCA 与任务加权只是同一评测材料的不同聚合；缺独立下游标准时以可解释的原始均值为优先。[C8 主观性与多指标评估的原项目说明](../../problem4/README.md)。
2. **前沿**：季度 p90/p95/Top-3、滚动 2/3 季度及逐模型线性条件分位数回归。分位回归是估计条件高分位的方法（[Koenker, 2001](https://www.aeaweb.org/articles?id=10.1257%2Fjep.15.4.143)）；但只有四个季度，不适合高自由度或随机前沿模型。
3. **历史结构**：时间项的 CV 误差和系数稳定性未显示独立价值，因此比较 compute-only 与 compute+time。后者只保留为结构情景，不能把时间系数称为纯技术效应。
4. **桥接**：已有等距、probit、Gompertz、折点 logistic 和规模校正实验。本轮另试六任务共享 Loss 斜率、任务特异截距的部分汇聚模型（7 参数）。目标为同一 75 行总能力，五折按家族完全隔离；若增益的家族配对 bootstrap 区间跨零或训练斜率退化，不升级。
5. **预测**：在相同滚动原点比较直接时间趋势、半速阻尼、持平朴素基线；长期 12/24 月只有条件情景，没有未来实测标签。采用 [Hyndman 与 Athanasopoulos 的 rolling-origin 思路](https://otexts.com/fpp3/tscv.html)，目标季度不得进入训练。

## 预注册判别

主指标依次为：家族外 RMSE（历史与桥接）、同一目标上的滚动原点 MAE（前沿与短期预测）；能力指数只报告 C8 一致性与排名稳定性。候选还必须满足单调/有界、参数可识别、足够的目标数、统计稳定与可解释性。若性能差异小于折间或家族重抽样波动，沿用更简单 Champion。已公开的既有测试只能称回顾性复核，不能称新盲测。12/24 月点预测不参与模型选择。

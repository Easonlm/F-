# Problem 4 Final Model Card

## Model

能力主定义为 C1 六基准的算术均值。历史前沿使用严格实体匹配且真正开放权重的 W1 样本，每季 p95；目标季度样本数少于 5 时该点仍列出但不用于方向结论。历史预测参照为仅算力的低维回归；算力加时间结构式只作条件情景。Loss→能力使用按可比性加权、0–100 有界且随 Loss 单调递减的二参数 logistic。未来 12/24 月输出为原有算力增长和时间项情景范围，不作为经长期回测验证的点预测。

## Formula and interface

- `Ability = mean(IFEval, BBH, MATH, GPQA, MUSR, MMLU-PRO)`，仅在六项完整时定义。
- `Frontier_t = empirical p95(Ability_i : open_w1_i, quarter_i=t)`，附 `n_t` 和最低样本标记。
- 条件桥接 `Ability_hat(L)=100 logistic(a-bL)`，`b>0`；其输入 Loss 必须注明与 C6 Loss 的可比性。主 C6 桥接家族外 RMSE 为 11.864 分。
- 机制路径通过最终 P2 Loss 与 P3 算力可行决策接入，仍需并列 E0/E1/E2；不能把 `Q_A` 与 `Q_B` 默认等同。

## Training data and validation

- C1 4576 行榜单，严格实体匹配后的开放权重 W1 独立模型 45 个；严格季度计数 22、16、5、2。
- 历史规模/时间比较：32 行、13 个组织，按组织分组 CV；compute-only RMSE 7.052，结构式 7.103，时间系数不稳定。
- C6 桥接：75 行、23 家族，五折家族隔离。高可比仅 7 行且同属一个家族。六任务共享斜率候选 RMSE 11.786，增益家族重抽样区间 [-0.043, 0.201]。
- 三个月严格前沿回测只有两个目标，其中一个目标季 n=2；六个月一个目标；12/24 个月没有直接观测目标，也无法校准覆盖率。
- C8 的 40 项详细任务与原能力均值 Spearman 0.9527；属于相关任务一致性，不是独立能力真值。

## Hyperparameters

前沿 p95、最小解释样本数 5、C6 中可比权重 0.35、家族分组五折均在比较前锁定。新增分位数回归的分位点 0.90/0.95 与 L1 正则 0.1，未根据目标误差重选。

## Evidence and failure modes

原有 bounded logistic 在受限 C6 中未被更复杂候选稳定超越。结构式时间项没有提供可分辨的组外提升，因此计算/技术的历史百分比不可作为实证贡献。W1 末季 n=2 与 C2 宽口径方向相反，故前沿涨跌不可稳定断言。短期持平基线对这两个目标更好，但没有长期升级证据。未来能力场景可说明假设下的方向和范围，不能提供现实预测置信保证。

## Extrapolation

任意超出 C6 Loss 或历史算力范围的桥接、超出 B1 训练范围的 P2 Loss 及 12/24 月预测均标为强外推。原能力锚 2025Q1 仅两个严格模型，预测应同时查看最近合格 2024Q4 的敏感性。

# 问题二最终模型卡

**模型状态：** 原 Model C 经复赛保留。N-D Winner=`classic`，Q Winner=`Q_by_N`。参数与指标均由本目录重跑产物自动生成。

## 使用方式与输入

`predict_final.predict_loss(N_B, D_B, Q_B, delta_p=0, lambda_p=1)`；`N_B` 是十亿参数，`D_B` 是十亿 token，`Q_B∈[0,1]` 是 B6/B7 半合成质量量表。`delta_p` 须由最终问题一配方模型相对同一参考配方中心化。默认 `lambda_p=1` 是未识别桥接情景。

主公式：`L=1.6897975629+0.3539803207N^{-0.3399765819}+1.2403055836D^{-0.2798781285}+0.3568073584(1-Q_B)^{0.9915433891}N^{-0.1620729110}+\lambda_p\Delta_p`。

## 拟合数据与独立层级

N-D 参数仅 B1 拟合；B1 按 N 留组 RMSE **0.00015118**。B2/B4/B5 零样本 raw RMSE 分别为 **1.2431/0.2927/0.1976**，显示跨来源误差。Q 参数仅 B6 拟合；B6 留 N RMSE **0.05235**，B7 新增 90 点 RMSE **0.04213**。这些外部文件曾用于旧轮次研究，属于可复查的开发证据，不是新封存盲测。

## 选择与不确定性

低维 N×D 交互及 broken-N 未改善 B1 组外预测；broken-N Jacobian 条件数 3.12e+10。Q×N×D 的 B7 RMSE 0.04117，相对 Champion 改善 2.28%；按 N 组自举的 RMSE 改善 95% 区间 [-0.00111,0.00262] 跨零，未通过预注册 5% 门槛。Q×N 的 `eta_N` B6 组自举区间 [0.1501,0.1909]；此区间仅反映 B6 半合成机制。

## 适用边界

- B8 仅机制诊断：与 B6 有 160 个相同输入却不同 Loss，B8 中 Q 响应方向相反。不得把 B8 写成统一 Q 律的外部通过案例。
- 有目标来源 Loss 标签时，可以在独立的条件应用层估计截距、仿射或 `log D` 修正；这些系数不能由 B1/B6 零样本推得，且不自动作用于 Q 或配方项。
- `lambda_p(N)` 和 `Q_A→Q_B` 均未识别。B 数据无联合配方/规模 Loss 标签，两个质量量表无配对锚点。
- Q 模型拟合来自半合成附件；大 N 和真实异源训练外推应作为敏感性，不给精确政策承诺。

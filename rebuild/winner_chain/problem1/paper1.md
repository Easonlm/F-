# 问题一详解：数据质量、质量冲突与领域配比（问答版）

> 本文依据项目现有代码和输出表写成，默认介绍**当前采用的方案**：质量评价沿用第一版四组等权 $Q$，配比预测采用第二版二阶 ALR–Ridge。文中的数值均是当前附件和模型的结果。$Q$ 是质量信号构造的**代理指标**，不是人工标注的真实质量；A12–A15 的 Loss 是外推估算值，不是 10B/70B 真实训练观测。

## 一、题目与数据

### Q1：问题一究竟要求解决什么？

**答：**它包含三项任务。第一，把每条文本的 22 个异质质量指标转为可比较的综合分数 $Q$，再汇总到来源域。第二，定义同一文本上指标意见相反的“质量冲突”，分析出现在哪些领域、可能是什么原因，并在扩展集核对。第三，研究 17 个训练领域的配比 $\mathbf p$ 如何影响 **13 个验证领域**的交叉熵 Loss，在 A6–A11 检验、用 A12–A15 讨论参数规模外推。Loss 越低通常表示相应验证集上的预测越好；它与文本 $Q$ 不是同一个量。

### Q2：A1–A15 分别是什么，为什么要分清？

**答：**A1 是 51,230 条、含七个来源域的质量信号抽样；A2 是 17,523 条 arxiv 扩展记录；A3 是 203,752 条 github 扩展记录，三份文件合计 272,505 **条记录**。A4/A5 按 `index` 配对，为 512 组 1M 训练配比和 13 维 Loss。A6/A7 是 256 组 1M 检验，A8/A9 是 256 组 60M 检验，A10/A11 是 64 组 1B 检验。A12/A13、A14/A15 分别是 63 组 10B、70B 配比及**模型估算** Loss。

| 配对附件 | 配比行数 | 用途 | Loss 性质 |
|---|---:|---|---|
| A4/A5 | 512 | 训练、模型选择 | 题目提供的观测值 |
| A6/A7 | 256 | 同规模 1M 检验 | 题目提供的观测值 |
| A8/A9 | 256 | 60M 规模迁移检验 | 题目提供的观测值 |
| A10/A11 | 64 | 1B 规模迁移检验 | 题目提供的观测值 |
| A12/A13 | 63 | 10B 外推诊断 | 估算值 |
| A14/A15 | 63 | 70B 外推诊断 | 估算值 |

配比的 17 列满足 $p_i\geq0,\ \sum_{i=1}^{17}p_i=1$，称为**单纯形约束**。CSV 中千分位舍入使行和最多偏离 1 约 0.004，代码先检查非负和缺失，再逐行归一。A1 的 arxiv 1,419 条、github 10,000 条与 A2/A3 重合；因此“272,505 条记录”不能写成“272,505 条独立文本”。扩展集比较时排除与 A1 重合的 ID。

### Q3：17 个训练领域与 13 个验证领域是一回事吗？

**答：**不是。每个输入配方有 17 个训练领域比例，输出则是 13 个验证领域各自的 Loss。训练领域中的 `nih_exporter`、`philpapers`、`enron_emails`、`europarl` 没有同名验证列，不能误以为模型只使用 13 个配比。质量样本的七个来源域与这 17 个领域也只部分对应；领域级 $Q$ 不能直接填成全部 17 个领域的实测质量。

## 二、从 22 个指标到 $Q$

### Q4：22 个指标中哪些是列表，为什么先压成一个数？

**答：**有 **8 个列表型、14 个标量型**。列表可能是分类器对各类别的 logits、单元素评分或四维评分，不能把一整个数组直接当作一个数与其他字段加权。项目采用下表规则，先将每个列表变成有明确含义的标量。

| 列表型指标 | 压缩规则 | 标量含义 |
|---|---|---|
| `fluency_en`、`ad_en` | 两个 logits 作 softmax，取索引 1 的概率 | 代码约定的正向类概率；分别解释为流畅、无广告 |
| `modernbert_cleanliness`、`modernbert_readability`、`modernbert_reasoning`、`modernbert_professionalism` | 六个 logits 的 softmax 后，计算 $\sum_{r=0}^{5}rP$r$/5$ | 归一到 0–1 的等级期望 |
| `fineweb_edu` | 取单元素列表的值 | 教育性原始分 |
| `qurater` | 四个分量的算术平均 | 四维综合原始分 |

其余 14 项是 `dsir_books/wiki/math` 和 11 项 `rps_*` 标量。**类别 1 的语义是本项目按字段说明采用的映射约定**；代码只做计算，不能仅凭数组的位置证明原始分类器的语义。正式论文应把该约定与字段来源一起交代。

### Q5：例如 `fluency_en = [-0.396, 0.446]` 是如何计算的？

**答：**两个数是 logits，不是两个已经相加为 1 的概率。正向类概率为

\[
P(y=1)=\frac{e^{0.446}}{e^{-0.396}+e^{0.446}}
=\frac{1}{1+e^{-0.842}}\approx0.699.
\]

代码用等价的 sigmoid 差值形式，并将差值截在 $[-35,35]$ 内以保持数值稳定。约 0.699 只表示该分类器对“索引 1”类别的相对倾向；后续还会使用 A1 的固定分位点做统一缩放，故最终进入 $Q$ 的标准化值不一定等于 0.699。

### Q6：哪些指标越大越好、越小越好，哪些要“适中最好”？

**答：**当前模型的方向是明确的**建模假设**，不是普适的语料价值判断。

| 方向 | 指标 |
|---|---|
| 越大越好 | `fineweb_edu`、`fluency_en`、四个 `modernbert_*`、三个 `dsir_*`、`qurater`、`ad_en`、`rps_doc_unigram_entropy`、`rps_doc_frac_unique_words`、`rps_lines_ending_with_terminal_punctution_mark` |
| 越小越好 | `rps_doc_frac_no_alph_words`、`rps_doc_frac_chars_top_2gram`、`rps_doc_frac_chars_top_3gram` |
| 适中最好 | `rps_doc_word_count`、`rps_doc_num_sentences`、`rps_lines_uppercase_letter_fraction`、`rps_lines_numerical_chars_fraction`、`rps_doc_mean_word_length` |

例如重复的二元/三元字符比例高，往往提示模板化或重复；文长过短可能信息不足，过长也可能异常，故长度用“中间高、两端低”的梯形效用。代码、数学公式和普通叙述的理想分布可能不同，所以这些方向和阈值必须作为适用范围说明。

### Q7：不同量纲怎么统一？缺失值怎么处理？

**答：**先对文长、句子数和二元/三元字符重复比例做带符号 `log1p`，压缩长尾。对单调正向指标，用 **A1** 的 1% 和 99% 分位点作截尾 Min–Max：

\[
z_{jk}=\operatorname{clip}\!\left(
\frac{x_{jk}-q_{.01,k}}{q_{.99,k}-q_{.01,k}},0,1\right).
\]

负向指标再用 $1-z_{jk}$ 反向。五项“适中最好”指标用 A1 的 1%、20%、80%、99% 分位点构造梯形：中段得 1，两端逐渐降到 0。标准化后 22 项均在 $[0,1]$，越高表示**按该项规则**越好。A2/A3 沿用 A1 标尺，使扩展对照可比。全量数据中 `modernbert_reasoning` 缺失 13 条、`modernbert_professionalism` 缺失 6 条；缺失后的标准化分用 A1 参考中位数填补，并记录数量。

### Q8：最终的 $Q$ 如何加权？为何不把 22 项直接等权平均？

**答：**先把指标分成教育性 $E$、可读性 $R$、洁净度 $C$、结构性 $T$ 四组。组内各子项等权，组间各占 $1/4$：

\[
Q_j=\tfrac14(E_j+R_j+C_j+T_j),\qquad 0\leq Q_j\leq1.
\]

教育组先把 `dsir_books/wiki/math` 三项平均成**一个子项**，再与 `fineweb_edu`、`modernbert_reasoning`、`modernbert_professionalism`、`qurater` 四项等权平均。因此这些项的最终权重分别是 0.05；三个 DSIR 每项是 $1/60\approx0.0167$。可读性组三项各 $1/12\approx0.0833$，洁净度组五项各 0.05，结构组七项各 $1/28\approx0.0357$。

这么做是为避免高度相似的 DSIR 指标重复计票，并让四类质量概念都有发言权。$Q$ 越大，仅说明这套 22 指标和权重下的综合代理分更高，不等于文本训练价值一定更大。备选的 CRITIC 权重、去掉最高最低组分后的鲁棒汇总和冲突惩罚都做了敏感性比较；没有独立人工真值可证明更复杂的版本更正确，因此主分析保留透明的四组等权分。PCA 只用于描述相关结构，不直接定义 $Q$。

### Q9：当前 $Q$ 算出了什么结果，扩展集验证了什么？

**答：**A1 七个来源域的平均 $Q$ 如下。区间是固定评分规则下按域重抽样 200 次的 95% bootstrap 抽样区间，未包含评分规则本身的误差。

| A1 来源域 | 样本数 | 平均 $Q$ | 95% 区间 |
|---|---:|---:|---|
| arxiv | 1,419 | 0.7647 | [0.7627, 0.7669] |
| commoncrawl | 9,640 | 0.7092 | [0.7078, 0.7106] |
| stackexchange | 10,000 | 0.6959 | [0.6945, 0.6974] |
| c4 | 10,000 | 0.6894 | [0.6877, 0.6911] |
| wikipedia | 10,000 | 0.6477 | [0.6462, 0.6495] |
| book | 171 | 0.6201 | [0.6082, 0.6310] |
| github | 10,000 | 0.5750 | [0.5736, 0.5766] |

排除重合 ID 后，A2 的新增 16,104 条 arxiv 平均 $Q=0.7616$，与 A1 arxiv 相差 $-0.0031$；A3 的新增 193,752 条 github 平均 $Q=0.5741$，与 A1 github 相差 $-0.0009$。这支持**同域评分分布的相近性**，不能证明 arxiv 对模型训练一定比 github 有价值。

## 三、质量冲突

### Q10：本文如何定义“质量冲突”？阈值为什么这样设？

**答：**先用统一方向后的指标或组分，预设三种“一个维度高、另一个维度低”的冲突：

1. `fineweb_edu` 高、`ad_en` 低：教育性信号与无广告信号相反；
2. `fluency_en` 高、`modernbert_cleanliness` 低：流畅性与洁净度相反；
3. 教育组 $E$ 高、可读性组 $R$ 低：内容重要性与阅读友好程度相反。

“高”定义为超过 A1 对应维度的第 75 百分位，“低”为低于第 25 百分位。三种任意一种成立即记 `conflict_any=1`。这是一条可复现的操作定义，25%/75% 不是自然常数；用 20%/80% 和 30%/70% 另做阈值敏感性。连续冲突强度定义为

\[
I_j=\max(E_j,R_j,C_j,T_j)-\min(E_j,R_j,C_j,T_j),
\]

它描述四组间最大落差，与二值冲突标记回答的问题不同。

### Q11：冲突有多少？扩展集规律一致吗？

**答：**A1 中有 **4,009/51,230 条，7.83%** 被上述任一规则标记。A1 各域冲突率：arxiv 5.07%、book 8.19%、c4 7.79%、commoncrawl 11.65%、github 11.87%、stackexchange 5.40%、wikipedia 2.94%。A2 arxiv 为 5.72%，A3 github 为 11.15%，与 A1 同域的量级接近。若阈值改为 20%/80%，A1 冲突率为 3.93%；改为 30%/70%，为 13.62%。因此论文中必须连同阈值一起报告冲突率。

### Q12：冲突为什么发生，发生后 $Q$ 怎么处理？

**答：**一种合理解释是指标测量不同性质：学术或代码内容可能信息密集，但不符合一般自然语言的可读性；网页语料可能通顺，却夹杂广告或模板；抓取、排版、分类器训练域差异也会造成矛盾。这些是**可能机制**，现有汇总表并未逐条完成因果归因。

模型比较过两种处理：连续惩罚 $Q_j^{pen}=\operatorname{clip}(Q_j-0.1I_j,0,1)$；若无广告标准化分低于 A1 第 10 百分位，则硬折减 $Q_j^{hard}=0.85Q_j$。前者使 A1 平均 $Q$ 下降 0.0368，但七域排序与原 $Q$ 的 Spearman 仍为 1.000。由于尚无完成的人工盲评证据，主结果**不自动扣分**，而是同时保留 $Q$、冲突类型和强度，供筛查与后续验证。冲突标记让“总分一样但短板不同”的文本可以被区别对待。

## 四、17 域配比如何预测 Loss

### Q13：为什么不能把 17 个比例当成普通独立变量？

**答：**因为 $\sum_i p_i=1$：任意一域增加，至少另一域必须减少。有截距的线性模型若同时放入 17 个原始比例，会发生完全线性相关；单个系数的解释还取决于“从哪个领域挪来份额”。本项目先将轻微舍入误差归一化，再用**加性对数比**（ALR）把 17 维单纯形转成 16 个相对坐标。零配比先加小的正伪计数 $\epsilon$，避免 $\log 0$。

### Q14：当前推荐的预测模型具体是什么？

**答：**第二版对第 (i) 个非参考域定义

\[
x_i=\log\frac{p_i+\epsilon}{p_r+\epsilon},\quad i\ne r.
\]

参考域 $r$ 是 `pile_cc`，$\epsilon=0.000249501$。对 16 个 $x_i$ 展开一次项、平方项和两两乘积，形成二阶特征 $\phi(\mathbf x)$，标准化后用多输出 Ridge 回归同时预测 13 个验证域：

\[
\widehat{\mathbf L}=\mathbf b+\mathbf B\,\operatorname{standardize}\{\phi(\mathbf x)\}.
\]

Ridge 的 $\alpha=10$。二阶项允许对数比与 Loss 有弯曲关系，也允许两组比例在预测函数中交互；惩罚项抑制在 512 组训练配方上过拟合。这里的系数依赖参考域、伪计数、标准化和其他变量，**不能像独立因果效应那样直接读出“某域越多必然越好”**。第二版比较 172 个候选，仅用 A4/A5 的 2×5 折训练集内部交叉验证按总体 RMSE 选型。第一版主模型是一次 ALR–Ridge，保留为对照。

### Q15：交互项能否证明两个领域互补？

**答：**不能单凭 $x_ix_j$ 系数证明。二阶项首先是提高预测弹性的数学特征；由于配比总量固定、变量互相牵制，某个交互系数的正负还受参考域和坐标变化影响。若要讨论互补，应在**指定同一基准配方、同一替代来源和可行配比范围**内计算联合调整相对单独调整的预测差，再检验对模型规格与样本扰动是否稳定。当前结果支持“非线性模型预测更准”，尚不足以断言某两个领域存在真实训练互补机制。

### Q16：如何解释“某个领域对 Loss 的影响较大”？

**答：**项目使用可解释的**局部置换**：在训练配比均值附近，把 `pile_cc` 减少 1 个百分点、目标域增加 1 个百分点，其余不变，计算 13 个验证域的**平均预测 Loss 差**。负数表示在此基准点和此替代方向上预测 Loss 下降。例如第二版在 9 种参考域/伪计数组合下，`dm_mathematics` 的差值约 $-0.0161$ 至 $-0.0119$，`ubuntu_irc` 约 $-0.0141$ 至 $-0.0109$，而 `enron_emails` 约 $+0.0788$ 至 $+0.1522$；三者方向在 9 种规格中一致。`gutenberg_pg_19`、`pubmed_abstracts`、`pubmed_central` 的方向随规格变化，不能下稳定结论。这些全是**模型在局部的预测比较**，不等于实际增减训练语料的随机实验，更不能脱离基准点推到任意高比例。

## 五、验证、图表和结论

### Q17：RMSE、MAE、$R^2$、Spearman、残差分别回答什么？

**答：**设真实 Loss 为 $L_n$，预测为 $\hat L_n$，残差定义为 $e_n=\hat L_n-L_n$。MAE 是 $\frac1n\sum|e_n|$，表示平均绝对误差；RMSE 是 $\sqrt{\frac1n\sum e_n^2}$，更重罚大误差；$R^2=1-\sum e_n^2/\sum(L_n-\bar L)^2$，越接近 1 越好，跨尺度发生系统偏移时可为负。Spearman 评估预测**排序**与真实排序是否一致，不能说明绝对数值准确。平均偏差 $\bar e>0$ 表示整体预测偏高。本文总体误差汇集所有“配方 × 验证域”，另报告 13 域平均 $R^2$ 和域内 Spearman，不能把两种汇总口径混为一谈。

### Q18：当前模型在训练、同规模检验和跨规模检验的成绩怎样？

**答：**训练集内部嵌套五折（每个外层折重新选型）总体 RMSE：第一版 0.3951、第二版 0.3340，下降 15.5%；第二版在 5/5 个外层折都更低。A6/A7 的既定 1M 检验上：

| 模型 | MAE | RMSE | 13 域平均 $R^2$ | 域内平均 Spearman |
|---|---:|---:|---:|---:|
| 第一版一次 ALR–Ridge | 0.253 | 0.3415 | 0.790 | 0.907 |
| 第二版二阶 ALR–Ridge | 0.189 | 0.2702 | 0.886 | 0.945 |

第二版 1M RMSE 降低 20.9%，13/13 个验证领域均下降，但 `dm_mathematics` 的剩余 RMSE 仍最高，约 0.572。A6/A7 已在第一版中被查看，第二版虽未用其标签拟合或调参，这仍是**复用的既定测试集**，不应写成全新盲测。

| 数据 | 第二版 RMSE | 预测减表中 Loss 的平均偏差 | 域内平均 Spearman | 解释 |
|---|---:|---:|---:|---|
| A6/A7：1M | 0.270 | +0.046 | 0.945 | 同规模预测较好 |
| A8/A9：60M | 1.596 | +1.506 | 0.941 | 排序较好，绝对值系统偏高 |
| A10/A11：1B | 2.702 | +2.619 | 0.877 | 绝对值明显偏高 |
| A12/A13：10B | 3.621 | +3.559 | 0.633 | 仅对估算标签作诊断 |
| A14/A15：70B | 4.009 | +3.942 | 0.554 | 仅对估算标签作诊断 |

这表明只用 1M 配比标签训练的函数没有学到模型规模变化引起的 Loss 基线下降。A12–A15 的配比是训练配比的子集，所谓外推主要沿**参数规模轴**，不是新配比空间；对估算 Loss 的匹配程度不构成大模型实测泛化证据。

### Q20：加入 $Q$ 后，配比到 Loss 的预测改善了吗？

**答：**第一版尝试用 A16 只对 **6 个** `direct/near_direct` 训练领域映射领域级 $Q$，其余 11 域保持未知。一次 ALR 基线的 1M RMSE 为 0.3415，加映射质量后为 0.3374；60M 为 1.6093→1.6070，1B 则 2.9820→2.9847。改善很小且不稳定。更关键的是，各域 $Q_d$ 在所有配方中固定，所谓质量特征是配比 $\mathbf p$ 的确定性函数；数据里没有“同一配比、不同质量”的训练对照。因此**不能独立识别 $Q$ 降低 Loss 的作用**，当前第二版主模型仍只写 $L=f(\mathbf p)$。

### Q21：这些结果最后能回答“所以呢”吗？

**答：**可以得到三层结论：

1. **质量评价层：**四组等权 $Q$ 和三类冲突规则提供了可复现的文本筛查尺度。A2/A3 与 A1 同域统计相近，但 $Q$ 尚缺人工真值与训练效用验证，尤其不能用一般文本指标贬低代码语料的任务价值。
2. **配比预测层：**针对 A4/A5 的 1M 配方，二阶 ALR–Ridge 比一次模型更准确；在既定 1M 测试集上 RMSE 为 0.2702。局部替代分析显示一些领域方向较稳定，但结论只对指定的替代路径、均值附近和当前数据支持范围成立；高比例恶化或领域互补尚需专门设计检验。
3. **跨规模层：**从 1M 搬到 60M/1B，域内排序仍有信息，但绝对 Loss 系统偏高；10B/70B 只有估算标签，当前结果不能宣称完成真实大模型外推。若要建立可信的 $L(N,D,Q,\mathbf p)$，需要跨规模训练数据及同配比异质量对照或独立校准集。

## 六、Q 评价体系验证（新增）

完整的四层验证结果、统计口径和论文用表见 [Q 评价体系验证](quality_proxy_validation.md)。

1. **内部一致性：**22 项标准化值均可由现有规则精确复算；14 个预设正向指标中有 4 个与 A1 总分 Q 呈负相关（三个 DSIR 和独特词比例），需作为指标张力报告。五项适中型指标的梯形上升段、平台和下降段均符合代码规则。指标与自身参与的总分相关，不能作为外部效度证据，因此同时报告剔除自身权重后的相关。
2. **人工文本外部验证：**140 条样本的空白盲评模板和独立分析脚本已备好，但尚无真实人工评分；当前结果文件只有表头，不能写入人机相关或评审一致性的数值结论。
3. **稳健性与独立性：**保留原 Q_baseline、Q_critic、Q_robust、权重扰动、冲突阈值与惩罚敏感性、四种聚合统计及 bootstrap 区间。A2/A3 分别剔除与 A1 重合的 1,419/10,000 个 ID 后，同域 Q 和冲突率仍处于相近量级，差异与区间已单列。
4. **Loss 下游关联：**ALR+mapped_Q 在 1M 和 60M 的 RMSE 略低于 ALR_only，1B 略高。mapped_Q 是配比与固定领域 Q 的函数，不能据此证明 Q 对 Loss 的独立因果作用。

四组等权 Q 是综合质量代理指标（quality proxy）；指标方向和权重仍是建模假设，人工效度和独立质量效应仍待新证据。

## 七、答辩时最容易问的五句

**“0.699 是最终质量分吗？”** 不是，它只是 `fluency_en` 的索引 1 概率，仍需固定标尺缩放、按组汇总。  
**“$Q=0.76$ 就表示有 76% 的文本是优质的吗？”** 不是，$Q$ 是 0–1 代理指数，不是合格率或概率。  
**“冲突的 7.83% 是客观真值吗？”** 不是，它依赖预设冲突对和 25%/75% 阈值。  
**“配比系数为正说明该领域有害吗？”** 不能直接这样说；必须指定减少哪个领域、从什么基准配方开始。  
**“10B/70B 的表能证明模型预测了真实大模型吗？”** 不能；这些 Loss 是附件中的模型估算值。

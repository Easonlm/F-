问题一 数据质量评价 质量冲突消解与领域配比建模

摘要

针对训练语料质量信号量纲不一、质量指标相互冲突以及领域配比受单纯形约束的问题，本文将 22 项质量信号统一到“越高越好”的固定标尺，构建四组等权的综合质量代理 Q，并对冲突文本单独标记与分析；随后对 17 域配比采用加性对数比变换和二阶 Ridge 回归，预测 13 个验证域的交叉熵损失。质量评价使用 A1–A3 的全部 272,505 条记录，配比模型利用 A4/A5 的 512 组训练配方选型。A1 的任一预定义冲突率为 7.83%；非重合扩展记录与 A1 的 arxiv、github 域级 Q 均值分别相差 −0.0031、−0.0009。第二版配比模型在 A4/A5 的嵌套交叉验证中，将 RMSE 从第一版的 0.3951 降至 0.3340；在既定 1M 测试集上，将 RMSE 从 0.3415 降至 0.2702，13 个验证域均获得改善。由于缺少人工质量真值及同配比异质量的训练实验，Q 仍应解释为质量代理，而非训练价值或因果效应；跨规模绝对 Loss 预测仍存在明显偏移。

关键词：训练数据质量；质量冲突；组合数据；领域配比；加性对数比；交叉熵损失

1 问题分析与数据划分

问题一包含质量评价、质量冲突消解和领域配比建模三个任务。前两个任务以文本为分析单位，第三个任务以训练配方为分析单位。两类数据的领域分类体系不同，因此不能直接把质量样本的 Q 当作 17 域配比实验中已观测到的质量变量。本文先分别建立质量评价模型与配比预测模型，再讨论有限的跨域映射及其识别边界。

表 1 给出各附件在本文中的用途。质量数据的三个文件均为压缩的 JSONL，逐行读取全部记录。配比表与对应 Loss 表通过 index 一一配对，所有配比行在入模前按行和归一。A1 与 A2 的 arxiv 记录有 1,419 个相同 ID，A1 与 A3 的 github 记录有 10,000 个相同 ID。因此扩展样本与 A1 的均值对比只使用扩展集中的非重合记录，避免将同一文本视作独立证据。

2 质量指标预处理与综合评价

2.1 指标标量化与统一方向

A1–A3 共有 22 项质量字段，其中部分字段为 logits 或多维列表。列表字段的类别语义按原数据来源的字段说明核对[3]。对二分类的 fluency_en 与 ad_en，先由两个 logits 计算正向类别概率；对六级 modernbert_*，计算 softmax 概率下的期望等级并除以 5；fineweb_edu 取单元素数值，qurater 的四个维度取等权均值。对于文档长度、句子数及字符重复比例等偏态字段，先作带符号的 log(1+|x|) 变换。各项效用函数由本文设定，而非直接采用来源文档中的建议权重。

对每个标量化指标，仅使用 A1 的参考分布确定缩放参数，并将同一参数应用到 A2/A3。令 t_jk 为第 j 条文本第 k 项指标经必要变换后的数值，a_k、b_k 为 A1 中该指标的 1% 与 99% 分位点。一般正向指标定义为

z_jk = clip[(t_jk - a_k)/(b_k - a_k), 0, 1]

负向指标取上述结果的补数。对长度、句子数等可能“适中最好”的指标，采用由 A1 的 1%、20%、80%、99% 分位点确定的梯形效用：20% 至 80% 分位保持高效用，两端线性下降并截断到 [0,1]。缺失值用 A1 对应处理后指标的中位数补齐，同时记录缺失数。全部 z_jk 因而位于 [0,1]，数值越大表示按该指标的当前效用规则质量越高。具体字段方向和阈值见生成结果 quality_indicator_rules.csv。

2.2 分组综合质量代理

22 项指标分为教育性、可读性、洁净度和文本结构四组。三个 DSIR 指标在样本中高度相关，先取组内均值作为一个子维度，避免在教育性组中重复计权。令 S_jg 表示第 j 条文本在第 g 组中的得分，教育性组为

S_j,edu = [z_j,fineweb + z_j,reasoning + z_j,professionalism + z_j,qurater + (z_j,dsir_books + z_j,dsir_wiki + z_j,dsir_math)/3]/5

其余三组使用组内均值，综合质量代理定义为

Q_j = (S_j,edu + S_j,read + S_j,clean + S_j,structure)/4, Q_j ∈ [0,1]

该结构保留四类质量信号的解释性。四组等权和部分指标的效用方向是建模假设；尽管本文比较了 CRITIC 权重和鲁棒聚合，其权重变化目前没有外部标签可校准，因此主分析保留透明的等权 Q。来源域 d 的质量水平取域内样本均值 Q_d=n_d^-1∑_j∈ dQ_j，并使用域内非参数 bootstrap 给出抽样区间。该区间不包含指标定义与权重选择的不确定性。

3 质量冲突定义与处理

3.1 冲突判定及扩展检验

不同评分器关注的属性并不相同，同一文本可能在某一维度得分较高而在另一维度得分较低。为使冲突可复核，本文以 A1 的 25% 与 75% 分位点为低、高阈值，预先定义三类冲突：教育性高而无广告概率低，流畅度高而洁净度低，教育组得分高而可读性组得分低。另用四组得分的极差 I_j=max_g S_jg-min_g S_jg 度量连续冲突强度。

A1 中任一预定义冲突的比例为 7.83%。阈值改为 20%/80% 时为 3.93%，改为 30%/70% 时为 13.62%，表明冲突率依赖判定口径。A1 的 arxiv 与 github 冲突率分别为 5.07% 与 11.87%，A2 的 arxiv 和 A3 的 github 分别为 5.72% 与 11.15%；扩展集呈现相近模式。由于 A1 与扩展集有重复 ID，扩展比较用于稳健性检查，不视为完全独立验证。

图 2 按 A1 25%/75% 阈值判定的任一质量冲突率。A2/A3 仅分别覆盖 arxiv/github。

3.2 冲突处理规则及证据边界

对冲突样本，本文同时保留原质量分、冲突类型和强度，不将低分维度的信息隐含地平均掉。作为候选处理，比较连续惩罚 Q_j^pen=[Q_j-0.1I_j]_[0,1]；另对无广告概率低于 A1 第 10 分位的文本，比较 Q_j^hard=0.85Q_j。连续惩罚使 A1 平均 Q 下降 0.0368，域级排序未改变；但这仅说明规则造成的数值变化，不能证明其更符合人工质量判断或更有利于训练。因此主结果仍报告未惩罚 Q，对冲突文本单独标记，并以分层抽样的 140 条文本准备两人独立盲评。盲评尚未完成，本文不将任何惩罚模型称为已验证的最优消解方案。

4 领域配比与 Loss 的预测模型

4.1 单纯形约束与特征构造

设第 s 个配方的 17 域比例为 p_s=(p_s1,…,p_s17)，其中 p_si≥0 且 ∑_i p_si=1。先按行和归一，再在各分量加入正数 ε，以参考域 r 构造 16 个加性对数比特征：

x_si = ln[(p_si + ε)/(p_sr + ε)], i ≠ r

对数比表示相对配比，能够处理总和为 1 的约束，其组合数据分析背景见[1]。配比到 Loss 的回归思路与 RegMix 的代理模型研究相近[2]，但本文的特征与选型由附件数据重新确定。参考域和零替换会影响带正则化模型的预测，因此两者进入训练集内的候选比较。采用二阶映射 φ( x)，包含 16 个一次项、16 个平方项和 120 个两两交互项，共 152 个特征。对映射后的特征标准化，拟合同时输出 13 个验证域 Loss 的 Ridge 模型：

L̂_s = b + B·std[φ(x_s)]; min Σ_s ||L_s − L̂_s||² + α||B||²_F

在 A4/A5 上进行两次五折交叉验证，从原始比例、ALR、CLR、ILR、二阶 ALR 与 RBF 模型中按总体 RMSE 选择模型和参数。选出的第二版模型采用二阶 ALR Ridge，参考域为 pile_cc，ε=0.000249501，α=10。二阶项用于刻画预测曲面中的非线性和交互，交互系数本身不直接解释为训练领域间的真实互补。

4.2 嵌套交叉验证与既定测试集比较

候选模型较多时，直接报告选型所用交叉验证误差可能偏乐观。为检验完整选型流程，本文在 A4/A5 中设置外层五折、内层三折：每个外层训练部分重新选择模型，再在未参与该次选择的外层验证部分计算误差。第一版与第二版的外层预测拼接 RMSE 分别为 0.3951 和 0.3340，第二版在 5 个外层折中均较低。

A6/A7 是原赛题指定的 1M 检验集。第二版的 RMSE 为 0.2702，较第一版的 0.3415 下降 20.9%；MAE 从 0.2526 降至 0.1890，13 个验证域的 RMSE 均下降。按 256 个测试配方重抽样，第一版减第二版 RMSE 的 95% bootstrap 区间为 [0.055, 0.088]。该区间只描述既定测试配方上的抽样波动，不包含重新选型的不确定性。由于 A6–A11 的结果曾用于第一版评估，它们不是第二版的全新封存盲测，尽管第二版未使用其标签拟合或选择参数。

4.3 领域置换与质量配比衔接

为描述领域关联，在训练配比均值 p 附近，从 pile_cc 转出 1 个百分点到目标领域 i，比较预测平均 Loss 的变化 Δ_i=13^-1∑_k[ L_k( p+0.01 e_i-0.01 e_pile_cc)- L_k( p)]。对三个参考域和三个零替换值组成的九种规格重复计算，16 个目标领域中有 13 个的效应符号一致。gutenberg_pg_19、pubmed_abstracts 与 pubmed_central 的方向随规格改变，不作为稳定结论。所有 Δ_i 均属于拟合模型在局部的条件预测，不是重新训练模型得到的因果效应。

质量数据与配比数据只在六个领域上有较可靠的直接或近直接映射。对这些领域的已映射比例集合 M，可定义 Q_mapped( p)=∑_i∈ Mp_iQ_i/∑_i∈ Mp_i，并同时记录已映射配比质量的覆盖量 ∑_i∈ Mp_i。第一版的探索性实验显示，加入该量后 1M RMSE 略降，但 Q_i 对每个领域固定，新增变量仍由 p 决定。缺少同配比、不同质量的训练结果时，无法识别 Q 对 Loss 的独立贡献。本文因此将质量代理与配比效应分别报告，供问题二进一步讨论，而不赋予虚假的独立质量系数。

5 结论与局限

本文完成了 A1–A3 全量质量信号的统一方向处理和样本级、域级 Q 构造，给出了可复核的冲突定义、扩展集对照与候选处理规则；同时建立了满足配比约束的 17 域到 13 域 Loss 预测模型。第二版模型在训练集嵌套交叉验证和既定 1M 测试集上均优于第一版，说明二阶对数比特征改善了当前数据条件下的配比预测。

现阶段，Q 仍是依赖指标方向与权重假设的质量代理，冲突惩罚尚无人工标签或训练实验验证；跨模型规模的绝对 Loss 预测仍存在系统偏移，估算标签也不能替代实测数据。后续应完成双人盲评与评审一致性分析，并在预先划分的规模校准数据或新训练实验上评估 Q 与规模因素的独立作用。

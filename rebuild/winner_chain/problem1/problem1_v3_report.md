# 问题一 V3：CLR 加性样条的条件推荐

## 现状与新增模型

当前跨问接口仍为二阶 ALR Ridge V2。V2 在 A4/A5 的五折嵌套 OOF RMSE 为 0.3340，在既定 1M 测试为 0.2702，表现可靠；但不同规模的绝对 Loss 存在偏差。新一轮在不改质量代理 Q 的前提下，仅优化 17 域配比到 13 域验证 Loss 的预测。A4/A5 的 512 个 1M 配方是唯一用于新模型拟合和超参数选择的数据。

V3 采用零替换后的中心化对数比（CLR），在每个配比方向上用三次样条表示平滑主效应，并用 Ridge 收缩：

\[
\hat L_j(p)=\beta_{0j}+\sum_{i=1}^{17}\sum_k\beta_{jik} B_k\{\operatorname{clr}_i(p+\epsilon)\}.
\]

这检验了一个具体假设：V2 的全二阶交互在 512 个配方上可能过于宽泛，而平滑、可加的领域主效应足以描述 1M 配比响应。另试了 ILR→PCA→二阶 Ridge，以检查交互是否集中在少量配比轴。两者都不在原 V2 的 172 个候选中。这里的响应是预测关联，不能解释为领域置换的因果效应。

## 同一协议比较

沿用 V2 的外层五折划分（`KFold(5, shuffle=True, random_state=20260924)`）；每个外层训练部分再做三折选择。V2 每折使用已记录的对应内层胜出规格，重新拟合后复算的 OOF RMSE 与原表精确一致。新模型的预设网格为零替换倍数 0.25/0.5、样条结点 4/6、Ridge α=1/10/100，共 12 项；ILR 低秩候选为保留 4/8/12 个主轴、相同两档零替换和三档 α，共 18 项。任何 A6–A15 标签均未参与选型。全训练最终参数用 A4/A5 的 2×5 折重复 CV 选出：V3 为零替换 0.25×最小正配比、4 结点、α=1；V3 的 CV RMSE 为 0.2462。

| 数据（每配方 13 域整体 RMSE） | V2 | CLR 加性样条 V3 | ILR 低秩二阶 | V3 对 V2 的判断 |
| --- | ---: | ---: | ---: | --- |
| A4/A5 嵌套 OOF，512 组 | 0.3340 | **0.2522** | 0.3676 | 5/5 外折改善 |
| 1M 实测，256 组 | 0.2702 | **0.2082** | 0.2963 | 11/13 域改善 |
| 60M 实测，256 组 | 1.5959 | **1.5614** | 1.5996 | 13/13 域改善，绝对偏差仍大 |
| 1B 实测，64 组 | **2.7021** | 2.7357 | 2.7883 | 仅 4/13 域改善 |
| 10B 估算标签，63 组 | **3.6212** | 3.6395 | 3.6328 | 不能充当真实规模验证 |
| 70B 估算标签，63 组 | **4.0090** | 4.0268 | 4.0204 | 不能充当真实规模验证 |

按配方行重抽样，V2 RMSE 减 V3 RMSE 的条件 95% bootstrap 区间：嵌套 OOF **+0.0818 [0.0653, 0.0973]**；1M **+0.0620 [0.0447, 0.0789]**；60M **+0.0345 [0.0076, 0.0612]**；1B **−0.0336 [−0.0613, −0.0073]**。它们条件于已建立的划分和模型，未覆盖开发集重复查看造成的选择不确定性。既定 1M/60M 测试使用同一批配方，因此两者的配比泛化证据并不独立。

逐域平均 Spearman 在 1M 从 0.9452 升至 0.9646、60M 从 0.9408 升至 0.9605；1B 基本不变（0.8767→0.8769）。配方平均 Loss 的 Spearman 在 1M 从 0.7153 升至 0.9289、60M 从 0.6823 升至 0.8932；1B 虽从 0.5667 升至 0.6630，但差异的行 bootstrap 区间 **[−0.0514, 0.2657]** 跨零，且绝对 RMSE 显著恶化。V3 在 60M、1B 的预测减观测 bias 仍为 **+1.4712、+2.6575**。域效应整体排序和绝对 Loss 应分开解释。

1B 的配方分布略远于训练配方：原比例空间最近训练配方的中位 L2 距离为 0.217，1M/60M 为 0.177；有 6.25% 的 1B 配方在至少一个训练 CLR 坐标范围外，1M/60M 为 2.73%。这提示支持域差异，但不足以单独证明 1B 退步的原因。10B/70B 的估算配方与训练配方重合，不提供独立配比泛化检验。

## 保留与拒绝

- **接入 V3 作为 1M 配比预测的条件候选。** 嵌套 OOF、既定 1M 与 60M 一致改善，代码、单独 artifact、逐域表和原始 CSV 核验均已形成。既定测试集已在旧研究中查看，应标注为回顾性比较。
- **保留 V2 为跨问正式接口。** V3 在 1B 的绝对 RMSE 有明确退步；P2/P3 的 `mixture_v2.joblib` 不变。60M 的改善不能解决跨规模共同截距偏差。
- **拒绝 ILR 低秩二阶候选。** 它在嵌套 OOF 与 1M 均劣于 V2，1B 也退步，未提供复杂度交换的收益。
- **不按 1B 测试结果事后设规模切换阈值。** 若获得新的多规模配方 Loss，可预设尺度交互或校准函数，再按规模和配方双留出决定是否进入跨问主模型。

运行 `python problem1/problem1_v3.py` 生成模型与对照表，再运行 `python problem1/verify_problem1_v3.py` 从原始 CSV 重算全部规模的 V3 RMSE 及各域 RMSE，并核对 V2 artifact SHA。独立探索的完整候选比较、配方支持域和排序 bootstrap 位于 `optimization_20260924/round2/q1/`。

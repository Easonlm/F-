## 1. 问题二到底要求解决什么

赛题 `算力约束下提升大语言模型能力的资源配置建模.md` 的问题二要求：在经典 $L(N,D)=E+AN^{-\alpha}+BD^{-\beta}$ 基础上，综合附件 A、B，建立包含参数量 $N$、训练 token 数 $D$、数据质量 $Q$ 和 17 领域配比 $\mathbf p$ 的广义规律；以 B1 为主拟合，做规定的跨来源检查，估计边际效用、弹性与质量和参数规模的替代关系，并讨论百亿参数以上的外推。

### 1.1 经典 Scaling Law

$$L_{ND}(N,D)=E+AN^{-\alpha}+BD^{-\beta}.$$

$L$ 是越低越好的验证 Loss；$E$ 是在模型和数据充分大时的渐近底座；$A,B>0$ 是两种不足的损失幅度；$\alpha,\beta>0$ 控制参数和数据收益递减的速度。$N,D$ 必须使用项目规定的 B 单位，否则系数 $A,B$ 的数值会变。增加 $N$ 或 $D$ 使正的幂律惩罚下降，但收益逐渐变小。这是预测拟合关系，不单凭回归证明投入的因果效应。

### 1.2 为什么经典模型不够

经典式子把训练 token 当成同质数据，无法表达质量不同和 17 个领域占比变化。题目因此要求 $L=f(N,D,Q,\mathbf p)$。项目中的 $Q_B$ 是 B6–B8 的 `Q_score`，$\mathbf p$ 是问题一的 17 维配比，满足 $p_i\ge0,\sum p_i=1$。问题一构造的质量代理 $Q_A$ 与 $Q_B$ 没有共同校准锚点，不能把两个数直接互换。

### 1.3 需要回答的具体问题

模型需回答：增加参数、token、质量分别预测减少多少 Loss；改变配比时必须从一个领域转给另一个领域，预测损失怎样变；在给定场景下哪种投入边际收益较高；$Q_B$ 提高 0.1 的损失改善可由多少参数增长替代；上述趋势在新模型族和更大规模是否站得住。不同资源的导数单位不同，不能仅比较导数绝对值就判定经济意义上的“最优投入”，还需要问题三的成本约束。

## 3. 问题一向问题二传递了什么

### 3.1 领域质量 $Q_A$

`problem1/outputs/tables/domain_quality_scores.csv` 保存问题一由 22 个指标构造的领域质量代理；问题二把它复制到 `problem2/outputs/tables/problem1_quality_proxy_import.csv`，用于解释与情景讨论。`problem2/run_problem2.py:problem1_bridge` 不从附件 A 重新拟合质量。问题一的 $Q_A$ 是领域/配比相关代理，而 B6 的 $Q_B$ 是半合成实验的质量控制刻度；没有同一实验同时测两者，故 $Q_A\ne Q_B$。V2 `QA_QB_scenarios.csv` 中 0.5、1、2 倍的映射斜率均标明 `empirical_anchor=False`，只是敏感性情景。

### 3.2 领域配比预测器

问题一最终使用二阶 ALR Ridge，模型存于 `problem1/outputs/models/mixture_v2.joblib`；变换函数见 `problem1/problem1_v2.py:transform`。它接收 17 维配比，预测 13 个验证领域的 Loss，再取均值 $\bar L_p(\mathbf p)$。V1 融合程序 `problem2/run_problem2.py:problem1_bridge` 读取该模型并设置均匀参考配比 $\mathbf p_0=(1/17,\ldots,1/17)$；因为模型文件没有保存 A4 训练配比均值，这个参考点是显式选择而非学得。V2 推荐预测函数 `problem2_v2/models.py:predict_recommended` 沿用该桥接。

### 3.3 局部配比置换

`problem1/outputs/tables/domain_effect_bootstrap.csv` 与 `v2_effect_stability_summary.csv` 在 V1 中合并为 `problem2/outputs/tables/mixture_effect_summary.csv`。从 `pile_cc` 转出 1 个百分点到 `ubuntu_irc`、`dm_mathematics`、`stackexchange` 的中心化预测 Loss 差分别为 **−0.015464、−0.010771、−0.001851**；转到 `europarl`、`nih_exporter` 则为 **+0.008928、+0.025477**。负号代表预测 Loss 降低。数值是问题一模型的局部预测差分，在 Model C 的 $\lambda_p=1$ 基准情景下同数值进入广义 Loss；不能把它当成真实训练干预效果。

### 3.4 问题一模型可迁移的范围

`problem2/outputs/tables/problem1_scale_transfer_metrics.csv` 表明问题一 V2 在 1M、60M、1B 的 RMSE 分别约 0.270、1.596、2.702，后两者有明显绝对水平偏移。因此只迁移**相同尺度内的配比差分**，不直接叠加问题一绝对 Loss。问题一质量映射仅有部分领域可直接/近直接对应，无法识别 $Q_A$ 对 B6 质量项的系数。

## 6. 第一阶段：经典 N–D Scaling Law

### 6.1 模型、估计与代码

经典式 $L_{ND}=E+AN^{-\alpha}+BD^{-\beta}$ 与 Chinchilla 一类加性资源不足模型一致，允许分别识别参数与 token 的边际衰减。V1 `run_problem2.py:fit_classic` 对 B1 做 SciPy `least_squares`，直接估计正参数，界为 $E\in[0,4]$、$A,B\in[10^{-5},100]$、$\alpha,\beta\in[0.005,2]$；四组初值择残差平方和最小者。它**不是**“对全部参数取对数再优化”。V2 `models.py:fit_nd` 用同样有界残差拟合候选，并保存 `nd_fit_comparison.csv`。V1 `classical_scaling_params.csv` 的多初值最大差均约 $10^{-11}$，说明同一 B1 目标上的数值收敛稳定。

### 6.2 实际参数与含义

`problem2/outputs/tables/classical_scaling_params.csv` 与 V2 `nd_fit_comparison.csv` 一致：

$$E=1.689797563,\quad A=0.353980321,\quad\alpha=0.339976582,\quad B=1.240305584,\quad\beta=0.279878129.$$

$$\boxed{L_{ND}=1.689797563+0.353980321N^{-0.339976582}+1.240305584D^{-0.279878129}.}$$

$N$ 增加一倍时，参数不足项乘 $2^{-0.339977}\approx0.790$；$D$ 增加一倍时，数据不足项乘 $2^{-0.279878}\approx0.824$。这说的是**对应损失分量**而非总 Loss 同比例下降；总 Loss 中还有 $E$ 和其余项。系数的物理尺度依赖 B 单位和同一评测 Loss 口径。

## 7. 为什么不用随机划分验证

B1 是同一 run 多检查点轨迹，随机拆行会让训练集直接看到验证点前后的同轨迹点，误差过于乐观。V1 `run_problem2.py:classical` 按 8 个 `N_params_B` 留一整组，逐次在其余 7 组拟合，并与训练均值 M0 比较，结果存于 `classical_scaling_cv.csv`。V2 `run_v2.py:nd_experiments` 对全部 N–D 候选重复留 N 分组；还取最小若干 $N$ 训练预测更大 $N$，以及每一规模的早期 $D$ 训练预测后期 $D$，详见 `nd_group_cv.csv`、`nd_scale_extrapolation.csv`。B1 classic 分组汇总 RMSE **0.00015118**，小到大 $N$ 截断汇总 RMSE **0.00014298**。留模型能防止直接检查点泄漏，仍只检验 Pythia 同族规律，不代表全新模型族的泛化误差。

## 8. B1 的结果为什么好得异常

V2 `diagnostics/source_shift.csv` 的 B1 全样本残差标准差约 **0.000146**；B1 的 8 个 $N$ 组有接近共同的 $D$ 网格，Loss 主要保留四位小数，且给定 $N,D$ 后近乎确定性。`diagnostic_report.md` 记录 $\log N$ 与 $\log D$ 相关近 0，排除了“完全由二者共线造成漂亮拟合”这一简单解释。该极低 RMSE 反映附件内部生成规律和精度，**绝不意味着对任意家族的 Loss 可预测到 0.000151**。B1 内部 $E$ profile 区间 [1.689718,1.689878] 和后述 bootstrap 窄区间，也均不覆盖跨来源系统误差。

## 10. 第一版 Q 模型

V1 `run_problem2.py:fit_quality` 固定 B1 的 5 个 N–D 参数，在 B6 单独估计 $G,\kappa$；`quality` 函数比较 additive、指数有效 token、幂有效 token 的两阶段/联合方式，按 B6 BIC 和复杂度选中 additive/two_stage。`generalized_scaling.py:predict_ndq` 实现

$$L_A=L_{ND}+G_A(1-Q_B)^{\kappa_A}+\lambda_p\Delta_p(\mathbf p),\quad G_A=0.362175024,\ \kappa_A=0.990735089.$$

$Q_B$ 升高使 $1-Q_B$ 下降、惩罚缩小；$Q_B=1$ 时退化为经典律。B6 RMSE **0.076068**、BIC **−1843.037**；B7_new RMSE **0.059515**；B8_new RMSE **1.392571**，明确失败。V1 参数与序列化模型在 `quality_scaling_params.csv`、`outputs/models/final_generalized_scaling.joblib`。它是后续比较的 Model A，不再是当前最终推荐 Q 结构。

## 12. 为什么最终从 Additive 优化为 Q×N

V2 预设选择逻辑在 `run_v2.py:report`：候选相对 additive 的 B7_new RMSE 至少改善 5%，B8 误差不变差，B6 BIC 至少下降 6；B8 只作为冲突排查，不能凭其较低误差选型。Q×N 达到门槛，参数来自 `quality_fit_comparison.csv`：

$$G_C=0.3568073634,\quad\kappa_C=0.9915434612,\quad\eta_N=0.1620729235.$$

它让 B6 留 $N$ RMSE 从 **0.081440→0.052346**，B7_new 从 **0.059515→0.042127**（改善约 29.2%），BIC 从 **−1843.04→−2113.75**，B8_new 仅从 **1.392571→1.341755**，仍极差。200 次按 B6 的 $N$ 组重采样得到 $\eta_N$ 的 95% 分位区间 **[0.148572,0.200805]**，`quality_model_intervals.csv` 可查。这支持“在 B6 半合成机制下，质量惩罚与模型规模关联”，不能写成真实训练中质量收益的因果律。

## 13. B8 为什么仍然失败

V2 `diagnostics/b6_b8_exact_overlap_conflicts.csv` 有 **160 个完全相同的 $(N,D,Q)$**，但 Loss 不同，B8 减 B6 的均值为 **−1.15361**；$Q=1$ 时约 −0.0125，$Q=0.1$ 时约 −2.1583，差异并非固定源截距。`quality_monotonicity.csv` 显示在可比较的同 $N,D$ 组内，“$Q$ 越高 Loss 越低”的比例：B6 为 100%，B7 全网格为 100%，B8_new 为 **0%**。B8 反向并有 0.5 的 Loss 下界。V1 对 B8_new 的观测减预测残差均值约 **−1.1517**，`b8_residual_trends.csv` 给残差与 Q 的相关 $r=0.9744$，与 $\log N$ 的相关仅 $r=-0.0126$。这同时表明**模型在 B8 上拟合差**，以及**B6 与 B8 的数据机制/质量语义本身冲突**。任何保持“更高 Q 一定更低 Loss”的单一单调律都不能同时无误解释两者；不能偷偷用 B8 标签重拟合后把它说成独立成功验证。

## 15. 来源偏移与 Source Calibration

B1→B2 的 raw 全量 bias 为 **−1.178442**，N–D 结构换成复杂候选后几乎不变。V2 `run_v2.py:nd_experiments` 把 B2 按每个 `run_id` 的早期 $D$、B4/B5 按 `family` 排序取约 20% 作**目标来源有标签校准集**，其余约 80% 为 holdout；`source_calibration_holdout.csv` 记录 raw、截距、仿射、$\log D$ 修正。截距可解释来源特定的有效 $E$，仿射形式是

$$L_s^{cal}(N,D)=a_s+c_sL_{ND}(N,D),$$

其中 $a_s$ 调整损失起点、$c_s$ 调整该来源的 Loss 尺度。Model B 将仿射形式**预先固定**，不对 Q 或 p 项做同样缩放，因为 B2/B4/B5 没有联合测量可识别它们。

| 来源 | 校准/holdout 行数 | 同一 holdout raw RMSE | 截距 RMSE | 仿射 RMSE | $\log D$ RMSE |
|---|---:|---:|---:|---:|---:|
| B2 | 203 / 826 | 1.033103 | 0.788919 | 0.695515 | 0.367362 |
| B4 | 12 / 45 | 0.248204 | 0.221161 | 0.091646 | 0.161231 |
| B5 | 9 / 35 | 0.188934 | 0.218046 | 0.161882 | 0.189887 |

B2 的 $\log D$ 修正局部更好，但不在 B4/B5 同时占优；其系数也需要该源标签。校准集内部 LOO 自适应选形式在 B5 误选截距，使 holdout **0.218045**，劣于 raw，因此最终 Model B 不是自适应形式选择。Model B 的 B2 仿射参数 $a=-0.240309,c=1.861322$，B4 $a=-0.815261,c=1.484678$，B5 $a=-0.716658,c=1.343569$，见 `model_B_source_calibrated.joblib`。全量 raw 的 B2 RMSE 1.243085 与后 80% raw 的 1.033103 **样本不同，不能直接相减当成校准收益**。有目标来源 20% 标签之后的改善不等于零样本泛化成功；多种校准方案已在同一数据上比较，结果属于描述性条件 holdout。

## 16. 领域配比 $\mathbf p$ 如何加入问题二

定义问题一模型给出的 13 验证领域平均预测 Loss 为 $\bar L_p(\mathbf p)$，再中心化：

$$\Delta_p(\mathbf p)=\bar L_p(\mathbf p)-\bar L_p(\mathbf p_0),\qquad\mathbf p_0=(1/17,\ldots,1/17).$$

最终附加 $\lambda_p\Delta_p$。中心化使参考配比的修正为零，避免把问题一的绝对预测截距误搬到 B1 的 Loss 标尺；局部两配比的差分也不依赖参考常数。$\lambda_p$ 是跨数据来源/规模的幅度桥接系数，当前 B 数据没有共同的 $(N,D,Q,\mathbf p)$ 实验来估它；代码中取 **1** 为基准情景，并做 0.5、0.75、1、1.25、1.5 敏感性，见 `bridge_assumptions.json` 和 `sensitivity_summary.csv`。V2 的 `p_scale_scenarios.csv` 另给常数、$N^{-0.1}$、$N^{0.1}$ 三种未识别情景，不能把它们当拟合结果。乘法桥接只在 `model_candidates.md` 提为候选/情景，项目没有证明比加性桥接更好。

## 18. 最终广义 Scaling Law：Model C

`problem2_v2/outputs/models/recommended_model.joblib` 的 `ND_model=classic`、`Q_model=quality_model`，预测实现在 `problem2_v2/models.py:predict_recommended`，与 `predict_nd,predict_q` 一致：

$$\boxed{L_C(N,D,Q_B,\mathbf p)=1.689797563+0.353980321N^{-0.339976582}+1.240305584D^{-0.279878129}+0.356807363(1-Q_B)^{0.991543461}N^{-0.162072924}+\lambda_p\Delta_p(\mathbf p).}$$

第一项 $E$ 是经典拟合底座；第二项是参数不足损失；第三项是 token 不足损失；第四项是低质量惩罚，$N$ 越大其绝对幅度按本半合成拟合越小；第五项是相对均匀参考配比的预测修正。$Q_B=1,\mathbf p=\mathbf p_0$ 时退化为经典式。$\lambda_p=1$ 是默认**情景假设**而非拟合参数。公式预测的是不同来源信息拼接后的情景 Loss，不表示五项均被同一联合实验识别。

## 20. 边际效用：从 Model C 推导

固定 $D,Q,\mathbf p$ 时，$Q×N$ 项也随 $N$ 改变，因此

$$\frac{\partial L_C}{\partial N}=-\alpha A N^{-\alpha-1}-\eta_NG(1-Q)^{\kappa}N^{-\eta_N-1},$$
$$\frac{\partial L_C}{\partial D}=-\beta B D^{-\beta-1},\qquad\frac{\partial L_C}{\partial Q}=-\kappa G(1-Q)^{\kappa-1}N^{-\eta_N}\quad(0<Q<1).$$

上述负号说明增加 $N,D,Q_B$ 在此模型内预测降低 Loss；“改善率”可记为 $-\partial L/\partial x>0$。$Q\to1$ 的导数需看单侧极限；$\kappa\approx0.992<1$ 时理论导数靠近 1 有弱奇异性，有限的 $Q+0.1$ 差分更易解释。$\Delta_p$ 当前实现不显式依赖 $N,D,Q$；若未来估计出 $\lambda_p(N)$，$N$ 导数还需增加 $\lambda_p'(N)\Delta_p$，本项目尚未做到。**V1 `generalized_scaling.py:derivatives` 只适用于旧加性模型，其 $\partial L/\partial N$ 少了 Q×N 交互项；V2 未保存 Model C 的导数 CSV。**

## 21. 弹性

Loss 弹性定义 $\epsilon_x^{(L)}=(x/L)(\partial L/\partial x)$；可约损失 $R=L-E$ 的弹性定义 $\epsilon_x^{(R)}=(x/R)(\partial L/\partial x)$。例如 $\epsilon_N=-0.03$ 表示局部 $N$ 增长 1% 时对应 Loss 约下降 0.03%，它是局部近似，不等于翻倍时的有限差分。代入上一节 Model C 导数即可计算新弹性。`problem2/outputs/tables/elasticities.csv` **现有数值仅属 V1 Model A**：$N=7,D=300,Q_B=0.6,\mathbf p=\mathbf p_0$ 时，$\epsilon_N^{(L)}=-0.0274$、$\epsilon_D^{(L)}=-0.0310$、$\epsilon_Q^{(L)}=-0.0957$；可约损失分别约 −0.1071、−0.1213、−0.3743。V2 未输出对应 Model C 场景表，不能把这些旧数值标注为 Model C 已运行结果。与成本相结合的边际投入比较留给问题三。

## 22. $Q_B$ 提升 0.1 等价于多少参数

固定 $D,\mathbf p$，先计算质量改善后的目标 $L_C(N,D,Q+0.1,\mathbf p)$，再求 $N_{eq}$ 满足 $L_C(N_{eq},D,Q,\mathbf p)=L_C(N,D,Q+0.1,\mathbf p)$，定义倍数 $r_N=N_{eq}/N$。V2 `models.py:equivalent_N` 在 $[N,10^{12}]$ 上用 `brentq` 精确求根，若上界仍达不到目标则返回无穷；它不是用导数随意近似。令 $H(N)=AN^{-\alpha}+G(1-Q)^\kappa N^{-\eta_N}$，则求解

$$H(N_{eq})=AN^{-\alpha}+G(1-Q-0.1)^\kappa N^{-\eta_N}.$$

$E,BD^{-\beta},\lambda_p\Delta_p$ 在两侧相消，所以在该模型结构下倍数与固定的 $D,\mathbf p$ 无关。`quality_equivalence_by_model.csv` 给 $D=20,300,2000$ 三个情景；下表为 $D=300,Q_B:0.6\to0.7$，**70B/120B 远超 B1 最大 11.97B，只能当结构敏感性**。

| 初始 $N$ | V1 加性等价 $N_{eq}$ | V1 倍数 | V2 Q×N 等价 $N_{eq}$ | V2 倍数 |
|---:|---:|---:|---:|---:|
| 0.1B | 0.1151B | 1.1514× | 0.1197B | 1.1967× |
| 1B | 1.3739B | 1.3739× | 1.2951B | 1.2951× |
| 7B | 13.4130B | 1.9161× | 9.9002B | 1.4143× |
| 70B | 373.2607B | 5.3323× | 112.9627B | 1.6138× |
| 120B | 1047.0793B | 8.7257× | 200.5827B | 1.6715× |

V1 的 Q 损失改善幅度与 N 无关，但 $AN^{-\alpha}$ 在大 N 已很小，想靠参数继续降低相同的绝对 Loss，必须把 N 增加很多，故出现 5×/8×。V2 的 $N^{-\eta_N}$ 让质量项也随规模下降，所需额外参数缩小至约 1.4–1.7×。这不是“实际加质量一定相当于 1.4× 参数”；换 Q 模型或 $Q_A\to Q_B$ 情景倍数会变化。`QA_QB_equivalence_sensitivity.csv` 的三个映射仅示范这种敏感性。

## 23. 领域替代关系

由于 $\sum_i p_i=1$，不能只提高一个领域；应做 $p_i'=p_i+0.01,p_j'=p_j-0.01$，其余不变，并保证 $p_j\ge0$。V1 `run_problem2.py:problem1_bridge` 生成的 `mixture_effect_summary.csv` 是主要结果，见第 3.3 节的五个实例。对同一 $\lambda_p$，广义模型中的损失变化是 $\lambda_p$ 乘该差分。`pile_cc→ubuntu_irc` 的 −0.015464 有 bootstrap 区间 [−0.019659,−0.011023]；`pile_cc→dm_mathematics` 的 −0.010771 有 [−0.013631,−0.007453]；`pile_cc→stackexchange` 的 −0.001851 有 [−0.002752,−0.000754]。这些只在已有配比支持域附近解释，不能延伸为任意大幅重配方的结论。

## 24. 领域互补

`problem1/outputs/tables/interaction_effects.csv` 有问题一的交互项探索，但当前没有同时通过 bootstrap、多个模型规格、样本支持和外部多重比较检验的稳定互补对。**当前没有足够证据确认稳定领域互补关系。**二阶 ALR 的交互系数也受单纯形约束和变量变换影响，不能看到一个正/负系数就断言两个领域在真实训练中互补。

## 25. 100B+ 外推

V1 `run_problem2.py:analyses` 把 B10 估算 Loss 与 B9 元数据按名字、$N,D$ 一对一连接，在 $Q_B=1,\mathbf p=\mathbf p_0$ 参考情景计算 classic 预测，输出 `large_model_extrapolation.csv`、`large_model_metrics_by_band.csv`、`large_scale_extrapolation.png`。128 个估算标签上的 RMSE **0.001093828**、MAE **0.000614049**、bias **+0.000614049**、Spearman 约 **0.999994**，分段 RMSE 为 100–300B 的 0.000676、300B–1T 的 0.001217、>1T 的 0.001923。数值漂亮可能因为估算表与经典幂律共用生成规律；B10 不是真实大模型训练 Loss，因此**不能称为真实 100B+ 验证**。V2 没有另用 B10 选型；Model C 在 $Q_B=1,\mathbf p=\mathbf p_0$ 与 classic 完全相同，所以这个参考情景的表可沿用作诊断，但并未检验 Q×N 或 p 在 100B+ 的效果。

## 26. Bootstrap 与不确定性

V1 `run_problem2.py:bootstrap` 以 B1 的 8 个模型规模为簇做 **200 次**有放回重采样，每次重估 N–D，再在同一 B6 表上重估 V1 Q；`bootstrap_parameters.csv`、`parameter_intervals.csv`、`bootstrap_equivalence.csv` 保存结果。它没有按 B6 新抽样 Q 簇，因此 V1 的 $G,\kappa$ 极窄区间不能解释为完整的质量实验不确定性。V2 `run_v2.py:q_experiments` 另以 B6 的 N 规模簇做 **200 次**重采样，固定 B1 参数，输出 `quality_model_cluster_bootstrap.csv` 和 `quality_model_intervals.csv`：$G$ 95% 区间 [0.348694,0.368501]，$\kappa$ [0.950084,1.036087]，$\eta_N$ [0.148572,0.200805]。两套 bootstrap 是**分阶段**的，当前项目尚未生成 Model C 全参数联合传播区间。B1 残差相关、来源口径偏差、B8 机制冲突、$\lambda_p$ 和 $Q_A\to Q_B$ 未识别均不包含在这些区间里。

## 28. 参考文献和它们如何影响本项目

`problem2_v2/literature_review.md` 列出论文和官方代码。Hoffmann 等的 Chinchilla 工作支持以 $E+A/N^\alpha+B/D^\beta$ 作强基线，并把 $C\approx6ND$ 用作算力约束灵感；本项目没有从其数据移植参数。Caballero 等的 Broken Neural Scaling Laws 启发平滑 broken-N 候选；本项目试了低自由度版本，但第 14 节证据不支持采用。Ye 等 Data Mixing Laws 启发配比与规模可能耦合；由于附件 B 不含 17 域配比联合实验，本项目最终只用中心化加性桥接，未确认乘法/规模变化律。Chang 等质量有效 token 工作启发 `effective_power/exp`；Goyal 等提示质量作用可能依赖资源量，因而测试 Q×D；最终这些候选均未胜过 Q×N。Biderman 等 Pythia 文献帮助解释同族检查点高度相关。文献提出某机制与本项目数据实际证明该机制是两回事。

1. **较强的同源证据**：B1 的经典 N–D 规律和留模型表现；仅限 Pythia 口径。

B1 只有 Pythia 同族；B2 与 B1 存在绝对 Loss 口径和训练阶段形状差；B4/B5 评测语料/口径未证实相同；B6–B8 是半合成，且 B8 的 Q 方向与 B6 相反、同键 Loss 冲突；$Q_A,Q_B$ 无共同锚点；附件缺 $(N,D,Q,p)$ 联合操纵实验，$\lambda_p$ 及其规模函数不能完全识别；二阶配比模型的互补证据不稳定；70B/120B 参数等价越过 B1 拟合上限；B10 是估算而非实测；V2 未产出 Model C 的导数/弹性表及可供问题三直接读取的新版 JSON 接口。这些限制分别对应数据来源、识别、外推和工程接口，不能统称“数据有限”。

# 常见答辩问题

1. **为什么用 Scaling Law？** 赛题要求在 $N,D$ 上建立可量化基线；正幂律可解释收益递减，B1 足以估 5 个参数。
2. **为什么用 B1 拟合？** 题目指定且它是 1,176 个同口径 Pythia 真实轨迹点；B2/B6 等不是同等级真实基线。
3. **B1 RMSE 为什么这么小？** 8 个规模共享近同 $D$ 网格、Loss 四位小数且近确定性；并非族外预测精度。
4. **B2 为什么很差？** raw bias −1.1784，且残差随 $\log D$ 变化；来源 Loss 口径和轨迹形状都变了。
5. **为什么不用 Broken Scaling？** 额外阈值/指数弱识别，$\delta$ 近零、BIC 变差，跨源无稳定收益。
6. **为什么 Q 最后采用 Q×N？** B6 留 $N$、B7 新点、BIC 均明显胜 additive，且未把 B8 用作拟合集。
7. **Q×N 的含义？** 本半合成拟合中低质量惩罚随 $N^{-0.1621}$ 衰减；不是已证明的真实训练因果效应。
8. **Q 是真实质量吗？** $Q_B$ 是 B6–B8 半合成实验的分数；问题一 $Q_A$ 是 22 指标代理，均不是无条件客观质量。
9. **$Q_A,Q_B$ 为什么不同？** 来源和构造不同，没有共同标注/训练锚点；数值相同不意味着效果相同。
10. **p 怎么进公式？** 问题一二阶 ALR Ridge 预测 13 域平均 Loss，相对均匀 17 域配比中心化后乘 $\lambda_p$。
11. **$\lambda_p$ 为什么不能直接估？** B 中没有同 $N,D,Q$ 下改变 17 域配比的联合实验。
12. **Q+0.1 等价参数怎么算？** 固定 $D,p$，令原 Q 下增加 N 的预测 Loss 等于原 N 下提高 Q 的 Loss，用 `brentq` 精确求根。
13. **V1 大模型倍数为何夸张？** 它的质量收益不随 N 变，而参数边际收益不断递减。
14. **V2 为什么改善？** Q×N 使质量惩罚也随 N 缩小，7B 1.414×、70B 1.614×、120B 1.672×；后两者是外推。
15. **B8 为什么预测不好？** 与 B6 有 160 个同键不同 Loss，且 Q–Loss 方向反转，不是单调公式调参可解决。
16. **是否数据泄漏？** B1 按模型规模分组，B7/B8 未入 Q 拟合；但 B2/B4/B5/B7 在 V2 被用于开发比较，不能再称全新封存测试。
17. **B10 为什么不能算真实验证？** 它的 `val_loss` 是估算标签，接近模型可能共享生成公式。
18. **最大优点是什么？** 参数、数据来源、模型选择、失败结果和证据等级都可追溯，最终结构保持简洁。
19. **最大缺点是什么？** 真实联合 $N,D,Q,p$ 实验缺失，B8 机制冲突，跨源绝对 Loss 标尺不统一。
20. **有更多数据最想补什么？** 同一评测语料、多个模型族和规模、固定 $N,D,p$ 改 Q 且固定 $N,D,Q$ 改 p 的真实受控训练，并留一整族作全新测试。
